贴吧楼层回复统计 使用说明
=========================

一、怎么打开
------------
双击文件夹里的「贴吧回复统计.exe」即可，不需要安装 Python，也不需要命令行。
第一次启动可能要等几秒，请耐心等窗口出现。

注意：整个文件夹要放在一起，不要只把 exe 单独拖出来，
      旁边的 _internal 文件夹是程序运行必需的。

如果 Windows 提示“已保护你的电脑”（SmartScreen）：
  这是因为 exe 没有数字签名，不是病毒。三种办法：
  1) 点「更多信息」→「仍要运行」；
  2) 直接双击文件夹里的「启动.bat」——它会自动解除文件锁定再启动；
  3) 右键 exe →「属性」→ 勾选「解除锁定」→ 确定。
  想彻底不弹，只能买数字签名证书（要花钱），个人工具一般不做。

想以管理员权限运行：
  双击「以管理员身份运行.bat」，弹出 UAC 确认后点「是」即可。
如果杀毒软件提示风险：
  这是打包工具生成的程序，常被误报，选择「允许」/「信任」即可。


二、三步搞定
------------
1. 用浏览器打开要统计的贴吧帖子，复制地址栏里的链接。
2. 把链接粘贴到软件第一个输入框里（每行一个，可以一次粘多个帖子）。
3. 点「开始统计」。抓完后会弹出提示，点「打开 Excel」就能看结果。

默认保存到桌面，文件名带日期时间。想换位置点「浏览…」。
「同时导出 Excel」默认不勾选；想要抓完自动生成表格就勾上，之后也可以在
「表格查看」里点「导出 Excel」随时生成。


三、结果怎么看
--------------
一个帖子会生成这几个工作表：

  回复统计   每个用户：昵称、用户名、等级、头衔、发了几层、多少条楼中楼、
             合计、占比（已按多少排序）
  楼层明细   每一层：楼层号、昵称、用户名、等级、头衔、时间、这一层有多少条楼中楼、正文
  楼中楼明细 每条回复：在哪层、谁回复的（昵称）、用户名、等级、回复了谁、时间、内容
  帖子信息   标题、吧名、链接、抓取页数、是否完整、备注

说明：昵称是浏览贴吧时最先看到的那个名字（带表情/符号）；用户名是注册时的
原始名字（比如「吧友1384」）。两个都会单独列出来。

一次抓多个帖子时，还会多出：

  总览       每个帖子的汇总
  用户总榜   跨帖子合并的回复排行

再次抓取新帖子时：
- 已经抓过的帖子默认跳过，不会重复抓；
- 新帖子会追加到现有结果里；
- 「表格查看」和「参与者」顶部可以切换帖子；
- 参与者默认“全部帖子”，也可以只看单帖；
- 想重抓某个帖子，用单帖的“重新抓取”，或先清空结果。

等级说明：等级和头衔（牌子）取自楼层作者信息；只回复楼中楼、没发过楼层的用户，
程序会用“贴吧新版网页”的接口自动补全（实测一个帖子里 46 人补到 45 人），
Excel 和参与者列表里都会写进去。极个别实在查不到的会显示“-”。
等级每次都会自动补全，不需要手动点。

三·四·五、抓取方式：默认匿名 + 可选关注增强
--------------------------------
默认匿名抓取，不需要 Cookie，也不需要先选模式。

默认匿名：
- 不读取、不发送 Cookie；
- 抓公开帖子的楼层；
- 按“全部 / 每层 10 / 50 / 100”的设置补全楼中楼；
- 看参与者、等级、最近发言、基本资料；
- 红绿灯只按“本帖发言”判定，不查关注列表。

如果只想看对方公开关注：
- 打开「设置 → 高级 → 关注增强」；
- 填入包含 BDUSS 的 Cookie；
- 只读取对方没有隐藏的公开关注列表；
- 隐藏关注仍然读不全；
- 关闭后立即回到匿名行为。

不需要 Cookie 也能做：
- 楼层、完整楼中楼（floor 翻页）；
- 参与者、等级、头衔；
- 基本资料、最近发言；
- 隐藏关注候选探测；
- 导出、筛选、对比、报告、备份；
- 红绿灯只看“本帖发言”。

关注增强开启后：
- 能读公开关注列表、较完整资料；
- 红绿灯按“发言 + 关注”判定；
- 隐藏关注且未命中禁止 → 黄灯 + ⚠；
- 仍然看不到完整的隐藏关注列表。

不再需要 STOKEN，也没有吧务功能。

三·五、查看参与者的资料
------------------------
抓完之后，切到「帖子统计」→「参与者」选项卡：

- 最左边是参与者列表（昵称、用户名、用户ID、等级、楼层、楼中楼、合计）；
- 点某一行，右侧是两张表：
  · 左表「关注的贴吧」：对方关注的吧和他在每个吧的等级，双击打开贴吧；
  · 右表「最近发言」：日期 / 类型（主题帖或回复）/ 贴吧 / 标题 / 内容，双击打开帖子；
  · 两张表都可以点表头排序（▲升序 / ▼降序）。
- 顶部可以设置条数（5~1000，默认 50）和日期范围：「近期」或「指定日期」；
  选「指定日期」后会出现开始 / 结束的 年 / 月 / 日 下拉菜单（不用记格式），
  默认开始是“三个月前”、结束是“今天”（按电脑当前日期算），
  还可以选「贴近结束日期」或「贴近开始日期」决定取哪一端的条数。
  切换近期/指定日期会自动重新查询当前选中的人。
- 「一键红绿灯」默认开启；可在「设置 → 通用」里关闭；批量刷新时条数和日期范围
  都按你当前设置来（默认每人 50 条），查询中再点一次可以停止。
- 默认匿名：只按本帖发言判定，不查关注列表，不会因为“关注隐藏”把所有人标黄；
- 开启了关注增强：按“发言 + 关注”判定；关注列表被隐藏的人，命中禁止仍然是 **红色**，
  没命中禁止时标 **黄色** 并加 ⚠（因为关注可能不全）。
  如果帖子里已经统计到他在本吧的等级牌，会自动补进「关注的贴吧」表。
- 界面里的 emoji 统一显示成 `[U+1F608]` 这样的代码（Tk 字体限制）；
  可以直接输入 `[U+1F409]` 这种代码；点「Emoji 代码」按钮也能输入十六进制代码后插入；
  界面统一显示代码，导出的 Excel / 报告保留原始 emoji；
  输入法打不出 emoji 时用代码即可，导出 Excel 仍是原始 emoji。
- 默认顺序：关注的贴吧按等级从高到低，最近发言按日期从新到旧。
- 关注列表如果被对方隐藏，表格下方会写“已从等级头衔/精选恢复 N 个，可能不全”。
- 隐藏时会出现「探测候选关注」按钮：
  · 只探测本帖发言吧、最近发言吧、本地标记里的吧；
  · 最多 30 个，手动触发，可中途停止；
  · 关注表新增「来源」列：公开 / 精选 / 等级恢复 / 候选确认；
  · 候选确认只代表“验证了这些候选吧”，仍然可能不完整，不能当成完整关注列表。
- 「表格查看」现在是独立选项卡（抓取 / 表格查看 / 参与者），里面是
  回复统计 / 楼层明细 / 楼中楼明细 三个子表，点表头排序，双击一行（或右键
  「打开链接」）打开对应主页/帖子；「导出 Excel」「打开 Excel」按钮也在这里。
- 复制：选中一行按 Ctrl+C，或右键选择“复制整行/昵称/用户名/用户ID”。
- 右上角「在浏览器打开主页」可以直接跳到对方的贴吧主页。

导出表格：「表格查看」选项卡里点「导出 Excel」，随时可以把当前数据保存成表格。
「同时导出 Excel」默认是**不勾选**的，需要自动导出时再勾。

Excel 里的超链接：
- 「昵称」「用户名」「回复者」点一下 → 打开这个人的贴吧主页；
- 「内容」点一下 → 打开这条发言所在的帖子。

三·七、查用户（按昵称 / 用户名 / 用户ID）
----------------------------------------
「查用户」选项卡可以单独查一个人，不需要先抓帖子：

1. 先选查询方式：用户名 / 用户ID / 昵称（分开选，避免昵称和用户名撞车）；
2. 输入对应内容，设置条数（5~1000）和日期范围（选「指定日期」后用年/月/日下拉菜单，可选贴近开始或结束日期），点「查询」；
3. 左边表格显示「关注的贴吧」及各吧等级，双击打开贴吧（对方隐藏的会从等级头衔 + 精选关注恢复一部分）；
4. 右边表格显示最近发言：日期 / 类型（主题帖或回复）/ 贴吧 / 标题 / 内容，双击打开对应帖子，点表头可排序；
5. 上方信息行显示：昵称 / 用户名 / 用户ID / 发言数 / 关注数 / 粉丝 / 发帖数（昵称和用户名来自客户端资料，不会乱码）；
6. 点「复制全部」可以把当前结果复制到剪贴板。

昵称查询会先在你当前抓到的参与者里找，找不到再用贴吧搜索；
仍找不到就换用户名或用户ID。资料页只展示发言和关注，不参与本地标记。

三·八、设置（通用 / 本地标记 / 使用说明）
--------------------
「设置」选项卡里有三个子页：

- 通用：
  · 「启用本地标记与红绿灯」默认开启；关闭后参与者列表不显示标记列，「一键红绿灯」禁用；
  · 选择是否在「参与者列表」「关注的贴吧」「最近发言」里按本地标记给行标色
    （红 / 黄 / 绿），改完立即生效，配置保存在本地。
- 本地标记（默认开启）：关闭时仍可维护名单；开启时每行一个贴吧名（带不带“吧”都行）：安全（绿）、警告（黄）、
  禁止（红），点「保存本地标记」生效。优先级：红 > 黄 > 绿。
  「导出 Excel」生成模板：两列（类别 / 贴吧名），类别可选 安全 / 警告 / 禁止；
  「导入 Excel」按同样格式读取并覆盖当前本地标记。
- 使用说明：就是这份说明，随时能看。

关于关注列表：用的是贴吧官方接口。
- 对方公开关注列表 → 直接列出完整列表（含每个吧的等级）；
- 对方隐藏了关注列表 → 从“等级头衔 + 客户端精选关注”恢复一部分，
  表格下方会显示“已恢复 N 个，可能不全”。

关于最近发言：优先用客户端 protobuf 的发言接口（翻页更深、带主题帖正文），
再用旧 PC 接口补回复，两边合并去重后按时间排序。

三·六、本地标记（快速筛人，默认开启）
--------------------------
默认开启。首次启动会显示一次免责提示：
“仅用于本地记录，请勿用于挂人、骚扰或公开曝光。”
之后可在「设置 → 通用」随时关闭；关闭后不显示标记、不标色、
「一键红绿灯」禁用，但已保存的名单不删除。

在「本地标记」选项卡里维护名单，把贴吧分成三类（每行一个吧名）：

  安全（绿色）  —— 自己人常驻的吧
  警告（黄色）  —— 需要留意的吧
  禁止（红色）  —— 红色名单吧

判定规则：

  免登录：只看本帖发言在哪些吧发过；不查关注列表。
  登录：  看本帖发言 + 关注列表；隐藏关注且未命中禁止时标黄 + ⚠。

  命中「禁止」→ 标记 🔴，整行标红
  命中「警告」→ 标记 🟡，整行标黄
  命中「安全」→ 标记 🟢，整行标绿
  都没命中   → 标记 ⚪

优先级是 红 > 黄 > 绿：只要命中一个禁止吧，就是红色，不会被绿色盖掉。
吧名带不带“吧”都行（程序会自动去掉末尾的“吧”再比较，全角/大小写也能识别）。
关闭红绿灯时：参与者列表不显示“标记”列，表格不标色，导出也不带标记。

状态栏还会写“命中禁止：某某吧”，方便你快速判断。

注意：标记依据的是“最近发言条数”里的发言（默认 20 条，可调到 200），
查得越多越准。想查得更全，把条数调大再点一次那个人。


三·九、这次新增的功能
------------------------
· 参与者筛选
  「参与者」页上方可以按关键词、等级、标记筛选：
  - 关键词匹配昵称、用户名、ID，也支持 [U+XXXX]；
  - 等级可选 Lv.1-3 / 4-6 / 7-9 / 10+ / 无等级 / 自定义；
  - 标记筛选只在「设置 → 本地标记」开启后可用；
  - 显示“当前 X / 共 Y 人”，点「清除筛选」恢复。

· 多帖对比
  「表格查看 → 参与者对比」：
  - 勾选至少 2 个帖子；
  - 可选交集 / 并集 / 仅在 A / A−B；
  - A、B 是勾选顺序的前两个；
  - 结果可导出 Excel。

· 单用户报告
  「查用户」或「参与者详情」里点「导出报告」：
  - 同时生成 .xlsx 和 .md；
  - 包含基本信息、关注贴吧、最近发言、本帖参与、本地标记（仅开启时）。

· 配置备份 / 恢复
  「设置 → 通用 → 配置备份 / 恢复」：
  - 备份成 JSON 或 ZIP；
  - 只含设置和本地标记，不含 Cookie；
  - 恢复前会预览并确认，并自动留一份临时备份。

· 全量楼中楼
  「抓取」页“楼中楼”可选：
  - 全部 / 每层 10 / 每层 50 / 每层 100；
  - 并发 1~3，默认 1；
  - 默认匿名已支持 floor 翻页全量；
  - 关注增强只影响关注列表，不改变楼中楼。

· 隐藏关注候选探测
  「查用户」或「参与者详情」里，关注列表隐藏时会出现「探测候选关注」：
  - 只探测本帖发言吧、最近发言吧、本地标记吧；
  - 最多 30 个；
  - 关注表「来源」列会标“候选确认”；
  - 仍然可能不完整，不能当成完整关注列表。

四、如果提示「被安全验证拦截」
------------------------------
贴吧会拦截非浏览器请求，这时需要借用你浏览器的登录身份（Cookie）：

1. 用 Chrome / Edge 打开目标帖子，确认能正常看到楼层。
2. 按键盘 F12，打开开发者工具。
3. 点顶部的「网络 / Network」，按 F5 刷新页面。
4. 在左侧列表点第一个以帖子数字开头的请求（类型 document）。
5. 右侧「标头 / Headers」→「请求标头 / Request Headers」，
   找到 Cookie: 这一行，复制冒号后面的整段内容。
6. 粘贴到软件的「Cookie」输入框（也可以点「从剪贴板粘贴」），
   再点「开始统计」。

只需要做这一次：
  软件默认勾选「记住 Cookie」，会把 Cookie 用你的 Windows 账户加密后
  存在本机（%APPDATA%\TiebaReplyStats），下次打开自动填入，不用再复制。
  Cookie 一般能用几个月，失效后重新粘贴一次即可。
  想删掉已保存的 Cookie，点输入框右边的「清除」即可。

为什么不能全自动读取？
  浏览器从 2024 年起对 Cookie 做了「应用绑定加密」，只有浏览器自己能解密，
  运行时还锁着 Cookie 文件，别的程序读不了。所以这一小步需要你手动复制。
  市面上所有第三方工具都一样，不是这个软件的问题。

注意：Cookie 等同于账号凭证，只在自己的电脑上使用，不要发给别人。
如果填了 Cookie 还是被拦，可以换个网络（比如手机热点）再试。


五、常见问题
------------
· 提示「没有抓到任何帖子」
  链接不对、帖子被删，或者被安全验证拦截了（按第四条处理）。

· 提示「声明 N 条回复，实际抓到 M 条」
  有些回复被系统折叠、删除，或需要登录才能看，这是贴吧的限制，
  表格的「备注」里会写清楚。

· 抓得很慢
  默认每 0.8 秒才请求一次，上千层的帖子要几十分钟，属于正常。
  把「请求间隔」调小会更快，但更容易被贴吧拦截；调大更稳。

· 只想统计主楼、不抓楼中楼
  把「抓取楼中楼回复」的勾去掉，速度快很多。

· 不想把 1 楼（楼主主帖）算进排行
  勾上「统计时不把 1 楼（楼主主帖）算作回复」。

· 建议
  第一次先拿一个小帖子试试，确认流程和结果没问题，再抓大帖子。


六、卸载
--------
直接删除 exe 和导出的 Excel 就行。程序不写注册表、不安装任何东西、
不联网上传你的数据（只有抓取时访问贴吧）。
