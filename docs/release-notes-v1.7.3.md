# 贴吧楼层回复统计 v1.7.3 更新说明

发布日期：2026-10-25

当前状态：

- 源码：v1.7.3
- Windows 成品：未打包
- 本文面向普通用户；技术改动见 `CHANGELOG.md`

## 一、这次更新的重点

这次主要重做了登录、验证码和内置浏览器的配合方式。

目标不是“自动破解验证码”，而是：

- 用户自己完成百度登录/验证；
- 软件只负责读取验证后的 Cookie；
- 能读到什么、填到哪里、是否保存，都明确显示。

## 二、登录与验证

### 1. 新增「登录与验证」设置页

设置中新增独立页面，集中显示：

- 当前模式：游客 / 登录
- 当前登录信息：未填写 / 仅 BDUSS / 完整 Cookie
- 内置登录状态
- 登录方式
- 记住 BDUSS / 记住完整 Cookie
- 记住内置登录
- 清除 WebView2 保存的登录
- 关注检测

### 2. 登录入口合并

抓取页不再同时放“登录百度”“自动获取 BDUSS”“自动获取完整 Cookie”多个相似按钮。

现在：

- 主按钮按当前状态显示明确文案；
- 仅 BDUSS 模式只保留 BDUSS；
- 完整 Cookie 模式才保留完整 Cookie；
- 登录成功后自动收起登录区。

### 3. 修复 Cookie 读取失败

修复了一个关键问题：

- WebView2 返回的 Cookie 对象不是普通字典；
- 旧逻辑序列化后 Cookie 名称为空；
- 导致明明登录成功，却读不到任何 Cookie。

现在会正确转换为：

- 名称
- 值
- 域名
- 路径

并支持 `TIEBA_SID` 作为登录态之一，不再只认 `BDUSS`。

### 4. 修复百度登录跳转被拦截

百度登录成功后可能跳转到 `www.baidu.com`。

旧白名单会立刻关闭窗口，导致 Cookie 未写入。

现在：

- 允许百度登录成功后的正常跳转；
- 检测到登录 Cookie 后再自动关闭；
- 仍拦截非百度域名。

### 5. 登录预检

自动获取登录信息后，会先用该 Cookie 请求一次贴吧首页。

- 成功：正常填入；
- 失败：仍保留 Cookie，但提示“预检未通过，可能被拦截”；
- 不把失败静默当成功。

## 三、验证码与续抓

### 1. 验证码中断保存已完成结果

验证码打断时，会保存：

- 已完成的帖子；
- 当前帖子的已抓楼层；
- 已抓评论；
- 失败页信息。

### 2. 登录模式也支持断点续抓

点击「重试失败部分」时：

- 只补失败页；
- 合并已有楼层；
- 合并已有评论；
- 不从头重抓已完成部分。

### 3. 第一页验证码也有占位

第一页尚未解析就被拦截时，会生成占位记录。

重试时优先补第 1 页，再继续后续页。

### 4. 登录完成后一键重试

如果存在未完成帖子，读取登录信息后会询问：

```text
有 N 个帖子未完成。
是否只重试失败部分？
```

## 四、WebView2 内置浏览器

### 1. 记住内置登录

可选保存 WebView2 登录态。

- 默认关闭；
- 开启后跨软件重启保留；
- 只影响本软件，不影响系统浏览器；
- 可单独清除。

### 2. 清除内置登录

支持选择：

- 只清除 WebView2 登录态；
- 同时清除当前 Cookie、BDUSS 和缓存。

### 3. 固定入口与导航限制

内置窗口只允许百度登录/验证相关域名。

非白名单页面会关闭。

### 4. 更紧凑的登录区

- 默认收起；
- 只显示一行摘要和主按钮；
- 需要时展开输入/获取；
- 登录成功后自动收起。

## 五、界面与使用体验

- 抓取页支持鼠标滚轮翻页；
- 登录区展开后不再挤压运行日志；
- 修复选择框按钮文字被截断/重叠；
- 关于页移除重复的「测试内置验证窗口」；
- 状态栏增加 F1 / Ctrl+Enter / Esc 提示；
- 使用说明窗口增加快捷键表；
- 登录成功文案按是否有旧结果区分：
  - 新用户提示去开始统计；
  - 有旧结果提示已完成帖子不会重抓。

## 六、测试中心

`Ctrl+Shift+C` 测试中心可进行：

- 模拟游客验证码；
- 模拟登录：完整 Cookie；
- 模拟登录：仅 BDUSS；
- 离线检查 PASS/FAIL；
- 测试内置验证窗口。

模拟使用假 Cookie：

- 不联网；
- 不写设置；
- 不覆盖结果；
- 不能替代真实百度验证码。

## 七、安全与隐私

- 游客匿名 Cookie 只在内存；
- 登录 Cookie 默认只在内存；
- 只有显式勾选“记住”才落盘；
- 不写日志、不写诊断、不导出；
- WebView2 持久目录独立；
- 清除软件数据会删除内置登录态；
- 不预装账号，不内置测试账号。

## 九、升级说明

当前仍是源码更新：

```text
python tieba_gui.py
```

不要用旧版 exe 判断 v1.7.3 功能。

如果使用旧版：

- 先关闭旧版；
- 更新源码/文件；
- 重新启动源码；
- 需要时重新获取一次登录信息。
