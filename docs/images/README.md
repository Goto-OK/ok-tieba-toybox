# 截图目录

截图由作者自行决定拍什么、上传哪些；本目录只提供位置和命名约定。

## 当前文件

```text
01-main.png          主界面 / 帖子统计
02-user-lookup.png   查用户
```

可选补充：

```text
03-excel.png         Excel 导出结果
04-login.png         登录 / 验证码（脱敏）
```

## 要求

- PNG；
- 宽度 1200~1600；
- 单张尽量小于 1MB；
- 只截应用窗口，不截整个桌面；
- 不上传含 Cookie、BDUSS、STOKEN、TIEBA_SID 的截图；
- 不暴露真实账号、真实用户昵称、用户 ID 或私人发言。
