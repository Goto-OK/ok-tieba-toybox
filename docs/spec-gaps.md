## 1. 当前结论

规范已经领先于 v1.3.1 代码。  
下面按“先正确、再完整、最后增强”排序，不按文件顺序。

## 2. P0：先修正确性/可用性

### G-01 吧务与 STOKEN 仍在代码里

- 规范：FR-013 已砍掉，不保存 STOKEN。
- 现状：仍有「吧务」标签、`bawu_deleted.py`、`stoken_store.py`、吧务测试。
- 验收：
  - 删除「吧务」标签和入口；
  - 删除 STOKEN 存储/读取；
  - 删除吧务接口客户端；
  - 不破坏默认匿名抓取。

### G-02 默认匿名 + 关注增强未落地

- 规范：默认匿名；「设置 → 高级 → 关注增强」默认关闭。
- 现状：仍是 `guest/login` 模式、首次选择、顶部切换。
- 验收：
  - 首次启动不再弹模式选择；
  - 顶部不再有 `[免登录] [登录]`；
  - 设置里出现关注增强开关；
  - 关闭时匿名，开启时校验 BDUSS；
  - 不按 Cookie 自动开启。

### G-03 红绿灯默认/批量/文案

- 规范：红绿灯默认开启；默认匿名批量只按 `user.bars`；按钮固定“一键红绿灯”。
- 现状：
  - `risk_enabled` 默认 `false`；
  - 按钮可能显示“一键红绿灯（仅发言）”并截断；
  - 默认匿名批量用 `_user_bar` 单吧。
- 验收：
  - 默认开启，保留设置开关；
  - 批量使用 `user.bars`；
  - 默认匿名批量不发资料/关注请求；
  - 按钮不截断，模式说明放按钮外。

### G-04 Emoji 显示与输入

- 规范：Tk 统一 `[U+XXXX]`；Excel/报告保留原始 emoji；提示说明。
- 现状：表格查看原始 emoji，参与者编码，不一致；无 Emoji 代码按钮。
- 验收：
  - 表格/参与者/查用户/日志一致；
  - 输入接受 emoji 和 `[U+XXXX]`；
  - 提供 Emoji 代码按钮；
  - 表格顶部有提示。

### G-05 多帖切换与导出范围

- 规范：表格查看支持“全部帖子（汇总）”；参与者默认全部；导出/打开共用帖子选择。
- 现状：表格只看第一个帖子；导出全部；打开上次文件。
- 验收：
  - 表格下拉：单帖 + 全部汇总；
  - 回复统计增加“参与帖子数”；
  - 明细增加“帖子”列；
  - 导出/打开支持全部/当前/勾选；
  - 打开生成临时工作簿。

### G-06 增量抓取与旧帖设置

- 规范：已抓帖子默认跳过；删掉的旧帖子默认保留；可选移除/询问；可选自动刷新旧帖。
- 现状：每次重新抓全部；无设置。
- 验收：
  - 已抓 tid 默认跳过；
  - 新增帖子追加；
  - 旧帖处理三选项生效；
  - 自动刷新默认关闭；
  - 刷新成功替换，失败保留。

### G-07 默认窗口与日志

- 规范：默认 980×820；日志最小 150px/8 行；表单可滚动。
- 现状：880×780，日志可能被挤出。
- 验收：
  - 1366×768 默认可见 6 行日志；
  - 最小窗口不裁切；
  - 日志可折叠。

## 3. P1：数据与安全

### G-08 Cookie 输入方式

- 规范：仅 BDUSS / 整段 Cookie 二选一，默认仅 BDUSS；只保存 BDUSS。
- 现状：单一 Cookie 输入框。
- 验收：
  - 两个选项；
  - 整段只提取 BDUSS；
  - STOKEN 不落盘。

### G-09 最近结果持久化

- 规范：SQLite `last_result.db`；自动/询问恢复；可选 DPAPI 加密。
- 现状：只在内存。
- 验收：
  - 完成后保存；
  - 停止保存部分；
  - 启动恢复/询问；
  - 清空删除文件；
  - 加密开关生效；
  - 不存 Cookie/标记。

- 现状：49 个 pytest，但未覆盖模式、红绿灯批量、多帖、持久化、Emoji。
- 验收：
  - 新增对应单元/集成测试；
  - 不依赖真实网络。
