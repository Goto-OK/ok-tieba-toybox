## 3. 1.7.0 已实现

### 使用说明 / 设置

- 独立非模态使用说明窗口；
- F1、顶部说明、关于页入口共用；
- 设置左侧 5 类，无独立「使用说明」；
- 数据/临时目录、清空数据在「结果与存储」；
- 恢复默认设置在「常规」；
- 关于页有「第三方许可」。

### 外观

- S1：浅色/深色/跟随系统；
- 强调色：蓝色/绿色/紫色/橘黄/粉色/青色/红色；
- S2 已从主程序移除：无鲸鱼女仆、皮肤包、横幅、侧图、动画；
- 表格表头统一主题色，不再出现系统白表头。

### 查用户 / 参与者

- 查询栏 / 条数 / 日期 / 时间偏向分行；
- 日期变化只标记“条件已变更”，手动查询；
- 底部操作栏固定；
- 成功结果缓存 60 秒；
- 资料与发言并发 2 路；
- 新查询忽略旧结果；
- 回复流异常明确提示；
- 原生 Windows Edit 内联输入 Emoji；
- 界面直接显示单色 Emoji；
- `[U+XXXX]` 输入自动还原。

### 红绿灯

- 先查发言，再判定；
- 完整关注列表才参与颜色；
- 隐藏/失败关注只提示，不标色；
- 发言查询失败不标色；
- 成功结果缓存 60 秒。

### 删除

- `safe_delete` 白名单路径；
- 拒绝越界、symlink、junction；
- 清空数据覆盖应用数据、日志、临时目录；
- 导出文件不动。

## 5. 1.7.0 增补（源码已实现，exe 未重建）

- 「导出发言」Excel：汇总 + 主题帖 + 回复，超链接；
- 导出前选日期；只导缓存，不自动补抓；
- 主题流不再固定 3 页，按日期深翻；
- 指定日期时条数只限制展示，抓取到范围起点；
- 表头规则：
  - 等级/楼层/楼中楼/合计/所在楼层/# 只排序；
  - 日期排序 + 范围筛选；
  - 类型只筛选；
  - 标记排序 + 筛选；
  - 文本列只筛选；
- 统一缓存：热内存 3 人/32MB，保存到软件关闭；冷 SQLite 本次运行；
- 一键红绿灯全部写冷库低优先，点开详情可命中；
- 缓存上限默认 200MB，可在设置中改（50–2000MB），到上限/降低时提示后果；
- 主题流默认 50 页，到上限提示继续 50 页/一直抓/停止；
- 导出/缓存覆盖区间分回复、主题单独展示；
- 清除入口在「结果与存储」。

### 5.1 本次收尾已实现

- 参与者「帖子范围」下拉宽度 56，完整显示序号 + 标题；
- 一键红绿灯标记结果写入 `user.mark_*`，刷新列表保留颜色；
- 「重新标记（本地）」按钮，只用缓存重算；
- 运行中隐藏继续未完成、禁用包含关注/重新标记/刷新列表/筛选；
- 停止后才显示「继续未完成」，完成后隐藏；
- 楼中楼解析保留 `user_id/user_name/portrait/showname`；
- 身份补全完成后才显示抓取完成，不再先显示完成再延迟补 ID；
- 抓取完成后自动补全缺失 uid，写回楼层/楼中楼；
- 恢复旧结果时后台补全缺失身份，完成后刷新并保存；
- 无 uid/username 时按昵称、portrait 兜底；
- 昵称搜索 exactMatch/fuzzyMatch 兼容 dict/list；
- portrait 通过 profile protobuf 反查 uid，无需 Cookie；
- 无 BDUSS 时展示 profile 片段关注，并标明不完整；
- 批量状态显示成功/跳过/失败；
- 顶部和表头标记筛选统一使用 `mark_level`；
- 主窗口默认 1400×900，启动居中；旧小尺寸回退默认；
- 「每次询问」旧帖处理已实现：移除 / 保留 / 取消。
