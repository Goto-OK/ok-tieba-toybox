- BDUSS / 整段 Cookie、自动/手动关注加载；

- 代理设置、网络超时/限流停止、完整性警告。

- 多帖切换、全部汇总、分帖统计；

- 超大导出拆分（含单帖分片）；

- 设置左侧分类、默认分类；

- 首次使用横幅，不弹窗；
