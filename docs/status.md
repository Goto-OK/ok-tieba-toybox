## 3. 1.7.0 已实现

### 使用说明 / 设置

- 独立非模态使用说明窗口；
- F1、顶部说明、关于页入口共用；
- 设置左侧 5 类，无独立「使用说明」；
- 数据/临时目录、清空数据在「结果与存储」；
- 恢复默认设置在「常规」；
- 关于页有「第三方许可」。

### 外观

- S1：浅色/深色/跟随系统；
- 强调色：蓝色/绿色/紫色/橘黄/粉色/青色/红色；
- S2 已从主程序移除：无鲸鱼女仆、皮肤包、横幅、侧图、动画；
- 表格表头统一主题色，不再出现系统白表头。

### 查用户 / 参与者

- 查询栏 / 条数 / 日期 / 时间偏向分行；
- 日期变化只标记“条件已变更”，手动查询；
- 底部操作栏固定；
- 成功结果缓存 60 秒；
- 资料与发言并发 2 路；
- 新查询忽略旧结果；
- 回复流异常明确提示；
- 原生 Windows Edit 内联输入 Emoji；
- 界面直接显示单色 Emoji；
- `[U+XXXX]` 输入自动还原。

### 红绿灯

- 先查发言，再判定；
- 完整关注列表才参与颜色；
- 隐藏/失败关注只提示，不标色；
- 发言查询失败不标色；
- 成功结果缓存 60 秒。

### 删除

- `safe_delete` 白名单路径；
- 拒绝越界、symlink、junction；
- 清空数据覆盖应用数据、日志、临时目录；
- 导出文件不动。

## 5. 1.7.0 增补（源码与 exe 已重建）

- 「导出发言」Excel：汇总 + 主题帖 + 回复，超链接；
- 导出前选日期；只导缓存，不自动补抓；
- 主题流不再固定 3 页，按日期深翻；

- 表头规则：

- 缓存上限默认 200MB，可在设置中改（50–2000MB），到上限/降低时提示后果；
- 主题流默认 50 页，到上限提示继续 50 页/一直抓/停止；
