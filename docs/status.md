## 3. 已实现

### 抓取

- 默认匿名；
- 关注增强可选，默认关闭；
- BDUSS / 整段 Cookie、自动/手动关注加载；
- 全量楼中楼、深度上限、跨页去重；
- 增量跳过、自动刷新旧帖、移除旧帖处理；
- 代理设置、网络超时/限流停止、完整性警告。

### 表格 / 参与者

- 多帖切换、全部汇总、分帖统计；
- 表格分页、每页行数、默认排序、排序箭头、隔行底色；
- 参与者分页、帖子范围、筛选、红绿灯；
- 参与者一键红绿灯：范围、筛选、包含关注、并发、继续未完成。

### 导出 / 报告

- 导出范围、用户范围、导出说明；
- 超大导出拆分（含单帖分片）；
- 单用户报告 Excel + Markdown；
- 多帖对比、对比说明；
- 空帖/空筛选处理；
- Emoji 在界面用 `[U+XXXX]`，Excel 保留原样；
- 曾用昵称。

### 存储 / 设置

- SQLite 最近结果、DPAPI 加密、自动/询问恢复；
- 不兼容结果保留/改名/清理；
- 本地标记导入覆盖/合并、条数预览；
- 设置左侧分类、默认分类；
- 关于页：路径、诊断、快速说明、许可、恢复默认、清空所有数据；
- 首次使用横幅，不弹窗；
- 单实例、窗口位置记忆、高 DPI 感知；
- 固定浅色主题。

### 清理

- 已移除吧务 / STOKEN；
- 已移除旧“选择使用方式”弹窗；
- Android 核心同步。
