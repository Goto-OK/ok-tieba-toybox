# 1.7.0 人工验收单

版本：1.7.0  
构建：`dist/贴吧回复统计_v1.7.0/`  
日期：2026-10-22

用法：逐项在软件里操作，通过打 `[x]`，失败写现象。

> A–H 针对旧 1.7.0 exe；I 组为 2026-10 增补，需要最新源码或重建后的 exe。

## A. 包与许可证

- [ ] **A1 版本**
  - 打开 `dist/贴吧回复统计_v1.7.0/贴吧回复统计.exe`
  - 窗口标题应为 `贴吧楼层回复统计 v1.7.0`
  - 设置 → 关于/帮助 → 版本显示 1.7.0

- [ ] **A2 第三方许可**
  - 关于/帮助 → 第三方许可
  - 应打开应用内只读窗口，显示 `THIRD_PARTY_NOTICES.md`
  - 不启动外部程序；可正常关闭，不卡死

- [ ] **A3 无皮肤残留**
  - 设置和安装目录中
  - 不应出现鲸鱼女仆、皮肤包、`assets/skins`

## B. 登录区

- [ ] **B1 开启增强**
  - 设置 → 常规 → 抓取增强 → 勾选
  - 抓取页应出现「登录 / 关注增强」
  - 若还没有 BDUSS，应弹确认框：去填写 / 稍后
  - 点「去填写」应切到抓取页并聚焦输入框

- [ ] **B2 仅 BDUSS**
  - 默认选中「仅 BDUSS」
  - 应看到：BDUSS 输入框、从剪贴板粘贴、如何获取？、应用、清除
  - 「记住 BDUSS」默认勾选

- [ ] **B3 完整 Cookie**
  - 切到「完整 Cookie」
  - 应看到：`Cookie：` 标签、粘贴、如何获取？、应用、清除
  - 「记住完整 Cookie」默认勾选

- [ ] **B4 无 BDUSS 重启**
  - 开启增强，不填 BDUSS
  - 关闭软件，再打开
  - 抓取页仍应显示登录区
  - 抓取增强仍保持勾选

- [ ] **B5 未填 BDUSS 开始**
  - 不填 BDUSS，点「开始统计」
  - 应提示需要 BDUSS，不应开始抓取

## C. 查用户

- [ ] **C1 条数/日期顺序**
  - 查用户第二行
  - 条数应在日期前

- [ ] **C2 时间偏向**
  - 近期模式：不显示时间偏向
  - 指定日期：显示「时间偏向：优先最近 / 优先最早」

- [ ] **C3 查用户标记**
  - 查询一个有本地标记的用户
  - 红绿灯应与参与者同顺序、同颜色
  - 应显示安全/可疑/警告和命中吧

- [ ] **C4 Emoji**
  - 输入或粘贴 😀：显示单色 😀
  - 输入 `[U+1F600]`：自动变 😀
  - 点 😀：查询栏下方出现原生 Edit
  - 在原生 Edit 里用 Win+. 输入 😀，点插入，能进查询框

## D. 表格与结果

- [ ] **D1 管理帖子结果**
  - 表格查看 → 帖子下拉框右侧「管理帖子结果」
  - 弹窗应在主窗口居中

- [ ] **D2 删除一个结果**
  - 勾选 1 个帖子
  - 点删除选中 → 确认
  - 结果数应少 1
  - 关闭软件再打开，删除后结果不应复活

- [ ] **D3 删除全部**
  - 全选 → 删除选中 → 确认
  - 当前结果应清空
  - 「打开 Excel」应禁用

- [ ] **D4 取消删除**
  - 打开管理弹窗，勾选后点取消
  - 结果不应变化

## E. 设置

- [ ] **E1 常规顺序**
  - 本地标记
  - 表格颜色
  - 抓取行为
  - 抓取增强
  - 界面
  - 默认设置
  - 设置备份 / 恢复

- [ ] **E2 设置备份**
  - 点「备份设置」
  - 选择 JSON/ZIP
  - 应成功保存，不含 Cookie

- [ ] **E3 设置恢复**
  - 点「恢复设置」
  - 选择备份
  - 预览 → 确认 → 设置生效
  - 当前结果不应被删除

- [ ] **E4 结果清理**
  - 结果与存储应有「删除当前结果」「清理旧版本残留」
  - 删除当前结果不应删除已导出 Excel 或本地标记

## F. 外观

- [ ] **F1 红色强调**
  - 外观 → 强调色 → 红色
  - 标题、开始统计按钮应为红色

- [ ] **F2 红→绿**
  - 再选绿色
  - 标题、开始统计按钮的字体和背景应同时变绿
  - 表格表头底色也应从红色变绿色
  - 危险按钮（清空所有本地数据）仍应保持危险红

## G. 网络与输入法

- [ ] **G1 真实抓取**
  - 匿名抓一个公开帖子
  - 能出楼层/楼中楼
  - 能导出 Excel

- [ ] **G2 真实验证码**
  - 仅 BDUSS 触发验证码
  - 应提示并切换到完整 Cookie
  - 完整 Cookie 仍被拦时，应提示更新 Cookie

- [ ] **G3 输入法 Emoji**
  - 微软输入法 / Win+. 在原生 Edit 中输入 😀
  - 点插入后进入查询框

## H. 窗口

- [ ] **H1 窗口尺寸**
  - 默认应以约 1400×900 居中打开
  - 旧的小尺寸设置应回退到默认
  - 最小 1100×760 下底部按钮完整

- [ ] **H2 125% / 150%**
  - Windows 显示缩放切 125%、150%
  - 主界面、查用户、参与者、管理弹窗无裁切

## I. 2026-10 增补

- [ ] **I1 身份补全完成才完成**
  - 抓一个楼中楼很多、用户名/portrait 混杂的帖子
  - 日志应出现“身份补全”
  - 补全和列表刷新完成后才显示“完成”
  - 完成时不应还需要手动刷新

- [ ] **I2 portrait 反查**
  - 构造/找到只有 portrait、没有 uid 的楼中楼用户
  - 抓取后应补出用户ID
  - 不要求登录 Cookie

- [ ] **I3 导出发言**
  - 查用户和参与者详情底部都有「导出发言」
  - 三张表：汇总/主题帖/回复
  - 标题和链接蓝色可点击

- [ ] **I4 表头筛选**
  - 文本/类型/标记表头可多选筛选
  - 日期表头可筛选范围
  - 等级/楼层/楼中楼/合计/所在楼层/# 只排序

- [ ] **I5 一键红绿灯状态**
  - 标记写入列表，刷新列表后颜色仍在
  - 改本地标记后点「重新标记（本地）」，不联网更新颜色
  - 运行中隐藏继续未完成，停止后才显示

- [ ] **I6 旧帖每次询问**
  - 设置 → 结果与存储 → 每次询问
  - 开始统计时弹：移除 / 保留 / 取消

- [ ] **I7 缓存设置**
  - 结果与存储显示热内存/冷库占用
  - 可调整上限并清除发言缓存
  - 清除后不影响 Excel、本地标记、最近结果
  - 详情命中缓存时显示“缓存于 X 分钟前”
  - 「刷新资料」应强制绕过缓存
  - 改更晚结束日期/更大条数时不能直接复用旧缓存

- [ ] **I8 ID 已齐全**
  - 抓取完成后参与者列表无“待补全”
  - 至少抽查 3 个之前缺失的用户

- [ ] **I9 结果与存储**
  - 页面按最近结果/运行日志/发言缓存/数据位置/危险操作分区
  - 日志可查看、打开目录、删除
  - 两个目录按钮分别写“打开数据目录”“打开临时目录”

- [ ] **I10 缓存边界**
  - 连续按下降箭头只改显示，不弹窗
  - 点「应用上限」只弹一次确认
  - 缓存满时批量不中断，状态栏提示一次
  - 表格、标记、最近结果不丢

- [ ] **I11 继续抓主题**
  - 主题流截断时按钮文本完整显示
  - 点继续只追加新页，不重复请求已缓存页
  - 刷新资料才完全绕过缓存

- [ ] **I12 候选关注**
  - 游客模式详情也显示「探测候选关注」
  - 匿名探测可确认候选吧
  - 公开关注完整时不显示该按钮

- [ ] **I13 游客隐藏关注标记**
  - 游客一键红绿灯可显示“关注列表未加载”⚠
  - 点开该行后 ⚠ 不消失
  - 说明只说未加载 profile 片段，不说“对方隐藏”

- [ ] **I14 查用户原生输入**
  - Windows 内容框直接是原生 Edit
  - 不显示 😀 按钮
  - 可直接输入/粘贴 Emoji，Enter 查询
  - 原生失败时回退 Entry + 😀

- [ ] **I15 弹窗位置**
  - 日志/许可/使用说明/导出范围/Emoji 兜底相对主窗口居中
  - 表头筛选仍锚定表头，不强制居中

- [ ] **I16 表格滚动条**
  - 参与者详情关注贴吧/发言有垂直滚动条
  - 查用户关注贴吧/发言有垂直滚动条
  - 发言表水平滚动条仍可用

- [ ] **I17 清空所有本地数据**
  - 清空后设置控件恢复默认
  - 表格查看帖子下拉没有旧标题
  - 参与者、详情、缓存状态同步清空

- [ ] **I18 导出发言覆盖**
  - 汇总页主题覆盖是精确最早~最晚
  - 回复覆盖单独计算
  - 无主题/无回复有明确文字

- [ ] **I19 恢复旧结果**
  - 启动时先补全身份再显示列表
  - 不出现“待补全”闪烁
