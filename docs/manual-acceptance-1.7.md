# 1.7.0 人工验收单

版本：1.7.0  
构建：`dist/贴吧回复统计_v1.7.0/`  
日期：2026-10-21

用法：逐项在软件里操作，通过打 `[x]`，失败写现象。

## A. 包与许可证

- [ ] **A1 版本**
  - 打开 `dist/贴吧回复统计_v1.7.0/贴吧回复统计.exe`
  - 窗口标题应为 `贴吧楼层回复统计 v1.7.0`
  - 设置 → 关于/帮助 → 版本显示 1.7.0

- [ ] **A2 第三方许可**
  - 关于/帮助 → 第三方许可
  - 应打开应用内只读窗口，显示 `THIRD_PARTY_NOTICES.md`
  - 不启动外部程序；可正常关闭，不卡死

- [ ] **A3 无皮肤残留**
  - 设置和安装目录中
  - 不应出现鲸鱼女仆、皮肤包、`assets/skins`

## B. 登录区

- [ ] **B1 开启增强**
  - 设置 → 常规 → 抓取增强 → 勾选
  - 抓取页应出现「登录 / 关注增强」
  - 若还没有 BDUSS，应弹确认框：去填写 / 稍后
  - 点「去填写」应切到抓取页并聚焦输入框

- [ ] **B2 仅 BDUSS**
  - 默认选中「仅 BDUSS」
  - 应看到：BDUSS 输入框、从剪贴板粘贴、如何获取？、应用、清除
  - 「记住 BDUSS」默认勾选

- [ ] **B3 完整 Cookie**
  - 切到「完整 Cookie」
  - 应看到：`Cookie：` 标签、粘贴、如何获取？、应用、清除
  - 「记住完整 Cookie」默认勾选

- [ ] **B4 无 BDUSS 重启**
  - 开启增强，不填 BDUSS
  - 关闭软件，再打开
  - 抓取页仍应显示登录区
  - 抓取增强仍保持勾选

- [ ] **B5 未填 BDUSS 开始**
  - 不填 BDUSS，点「开始统计」
  - 应提示需要 BDUSS，不应开始抓取

## C. 查用户

- [ ] **C1 条数/日期顺序**
  - 查用户第二行
  - 条数应在日期前

- [ ] **C2 时间偏向**
  - 近期模式：不显示时间偏向
  - 指定日期：显示「时间偏向：优先最近 / 优先最早」

- [ ] **C3 查用户标记**
  - 查询一个有本地标记的用户
  - 红绿灯应与参与者同顺序、同颜色
  - 应显示安全/可疑/警告和命中吧

- [ ] **C4 Emoji**
  - 输入或粘贴 😀：显示单色 😀
  - 输入 `[U+1F600]`：自动变 😀
  - 点 😀：查询栏下方出现原生 Edit
  - 在原生 Edit 里用 Win+. 输入 😀，点插入，能进查询框

## D. 表格与结果

- [ ] **D1 管理帖子结果**
  - 表格查看 → 帖子下拉框右侧「管理帖子结果」
  - 弹窗应在主窗口居中

- [ ] **D2 删除一个结果**
  - 勾选 1 个帖子
  - 点删除选中 → 确认
  - 结果数应少 1
  - 关闭软件再打开，删除后结果不应复活

- [ ] **D3 删除全部**
  - 全选 → 删除选中 → 确认
  - 当前结果应清空
  - 「打开 Excel」应禁用

- [ ] **D4 取消删除**
  - 打开管理弹窗，勾选后点取消
  - 结果不应变化

## E. 设置

- [ ] **E1 常规顺序**
  - 本地标记
  - 表格颜色
  - 抓取行为
  - 抓取增强
  - 界面
  - 默认设置
  - 设置备份 / 恢复

- [ ] **E2 设置备份**
  - 点「备份设置」
  - 选择 JSON/ZIP
  - 应成功保存，不含 Cookie

- [ ] **E3 设置恢复**
  - 点「恢复设置」
  - 选择备份
  - 预览 → 确认 → 设置生效
  - 当前结果不应被删除

- [ ] **E4 结果清理**
  - 结果与存储应有「删除当前结果」「清理旧版本残留」
  - 删除当前结果不应删除已导出 Excel 或本地标记

## F. 外观

- [ ] **F1 红色强调**
  - 外观 → 强调色 → 红色
  - 标题、开始统计按钮应为红色

- [ ] **F2 红→绿**
  - 再选绿色
  - 标题、开始统计按钮的字体和背景应同时变绿
  - 表格表头底色也应从红色变绿色
  - 危险按钮（清空所有本地数据）仍应保持危险红

## G. 网络与输入法

- [ ] **G1 真实抓取**
  - 匿名抓一个公开帖子
  - 能出楼层/楼中楼
  - 能导出 Excel

- [ ] **G2 真实验证码**
  - 仅 BDUSS 触发验证码
  - 应提示并切换到完整 Cookie
  - 完整 Cookie 仍被拦时，应提示更新 Cookie

- [ ] **G3 输入法 Emoji**
  - 微软输入法 / Win+. 在原生 Edit 中输入 😀
  - 点插入后进入查询框

## H. 窗口

- [ ] **H1 900×640**
  - 抓取页 + 登录区
  - 登录区和开始统计不被裁切
  - 查用户/参与者底部按钮完整

- [ ] **H2 125% / 150%**
  - Windows 显示缩放切 125%、150%
  - 主界面、查用户、参与者、管理弹窗无裁切
