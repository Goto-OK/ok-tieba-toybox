# 凭据说明：Cookie（可选）

## 1. 一句话

- 默认匿名抓取，不需要 Cookie；
- Cookie 只用于可选的「关注增强」；
- 关注增强只能读取对方**没有隐藏**的公开关注列表；
- 不使用 `STOKEN` 做任何写操作；默认只保存 BDUSS；
- 「记住 BDUSS」默认勾选，可用 DPAPI 保存 BDUSS；
- 「记住完整 Cookie」默认勾选，可用 DPAPI 保存完整内容；
- 取消勾选则只在本次会话使用；
- 不提供吧务、删除内容恢复等写操作。

## 2. Cookie 里有什么

```text
Cookie: BAIDUID=...; BDUSS=...; STOKEN=...; PSTM=...
```

| 字段 | 作用 | 本软件 |
|---|---|---|
| `BDUSS` | 登录态核心 | 关注增强只校验它 |
| `STOKEN` | 敏感操作令牌 | **不使用**；仅完整 Cookie 记住时可能随内容保存 |
| `BAIDUID` | 浏览器/设备标识 | 可随 Cookie 带上，不单独解析 |
| 其他 | 统计/风控 | 可随 Cookie 带上 |

软件接受整段 Cookie，也接受只写 `BDUSS=...`。

抓取页登录方式：

- **仅 BDUSS**（默认，推荐，只发送 BDUSS）；
- **完整 Cookie**（验证码时使用，可能包含其他 Cookie）。

两种方式不改变统计功能；完整 Cookie 主要用于通过安全验证。  
默认只持久化 BDUSS。  
「记住完整 Cookie」默认勾选；保存时完整内容可能包含 STOKEN，仍不使用 STOKEN 做写操作。

## 3. 默认匿名

- 不读取、不发送 Cookie；
- 楼层、完整楼中楼、参与者、等级、头衔；
- 查用户基本资料、发言；
- 隐藏关注候选探测；
- 查用户时匿名尝试读取公开关注（不保证成功）；
- 红绿灯只看本帖发言；
- 导出、筛选、对比、报告、备份。

匿名不是残废模式，核心能力全部可用。

## 4. 关注增强

入口：

```text
设置 → 高级 → 关注增强（需要 Cookie）
```

- 默认关闭；
- 开启时必须提供包含 `BDUSS` 的 Cookie；
- 只用于读取公开关注列表；
- 不改变抓取、楼中楼、导出；
- 关闭后立即回到匿名行为；
- 不因为检测到 Cookie 就自动开启；
- 恢复上次明确开启状态；无 BDUSS 时保持开启并提示填写；
- 第一次开启时验证一次 BDUSS；
- 任何页面都不显示 Cookie/BDUSS 明文。

## 5. 能力矩阵

| 能力 | 默认匿名 | 关注增强开启 |
|---|---|---|
| 抓取 / 完整楼中楼 | ✅ | ✅ |
| 参与者 / 等级 / 头衔 | ✅ | ✅ |
| 基本资料 / 发言 | 🟡 有限 | ✅ 较完整 |
| 公开关注列表 | 🟡 匿名尝试，可能失败/不完整 | ✅ 公开部分完整 |
| 隐藏关注完整列表 | ❌ | ❌ |
| 隐藏关注候选探测 | ✅ | ✅ |
| 红绿灯：本帖发言 | ✅ | ✅ |
| 红绿灯：关注列表 | ❌ | ✅ |
| 隐藏关注标黄 | ❌ | ✅ |
| 导出 / 筛选 / 对比 / 报告 / 备份 | ✅ | ✅ |
| 吧务删除内容 | ❌ | ❌（已砍掉） |
| 发帖 / 回复 / 关注 / 签到 | ❌ | ❌ |

## 6. 硬规则

- Cookie 不是必需项；
- Cookie 不等于权限；
- 有 Cookie 也不能完整枚举隐藏关注；
- 默认不保存 STOKEN；完整 Cookie 记住需用户主动勾选；
- 不提供吧务功能；
- 不因为检测到 Cookie 自动开启关注增强；
- 恢复上次明确开启状态；
- 免登录/匿名模式不发送 Cookie。

## 7. 安全

- Cookie 本机 DPAPI 保存；
- 不写日志、不导出、不进设置备份；
- 换电脑或换 Windows 用户后需要重新填写；
- 不要把 Cookie 发聊天、截图或提交仓库。

## 8. 常见误解

- “不填 Cookie 就只能看 10 条楼中楼” → 不是，匿名也能 floor 翻页抓全；
- “有 Cookie 就能看隐藏关注” → 不能，隐藏关注仍不可完整枚举；
- “没 Cookie 也能看关注” → 只能匿名尝试，可能失败且不完整；
- “Cookie 就是权限” → 不是，吧务功能已砍掉；
- “要填 STOKEN” → 不需要，本软件不使用 STOKEN 做写操作；完整 Cookie 仅用于通过验证。
