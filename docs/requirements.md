# 需求与边界

## 1. 背景

贴吧帖子页的楼层和楼中楼没有方便的批量导出工具。本项目面向需要统计“谁回复了多少、
发了什么”的个人用户，提供 Windows 桌面程序、命令行和 Android 版。

## 2. 目标用户

- 想导出某个帖子参与情况的普通用户；
- 需要按用户筛查“成分”（关注吧、最近发言）的用户；
- 想在手机上临时抓一个公开帖子的人。

## 3. 功能需求

### 3.1 抓取

- 支持一个或多个帖子链接/帖子 ID；
- 自动识别总页数，逐页抓取主题楼层；
- 抓取楼中楼（登录态：`totalComment` + `/p/comment`；游客态：客户端 protobuf，每层前 10 条）；
- 支持“最多页数”“是否抓楼中楼”“是否导出”等选项；
- 支持中途停止。

### 3.2 统计与导出

- 按用户汇总：楼层数、楼中楼数、合计、等级、头衔、首次出现楼层；
- 导出 Excel：总览、用户汇总、每帖工作表；
- 包含超链接、冻结首行、筛选、合计行。

### 3.3 参与者

- 列表展示所有参与者；
- 点选后显示：关注贴吧（含等级）、最近发言（日期/类型/贴吧/标题/内容）；
- 支持条数（5~1000）与日期范围；
- 支持一键批量刷新红绿灯（按用户设置条数与日期）。

### 3.4 查成分

- 按用户名 / 用户ID / 昵称查询；
- 显示昵称、用户名、ID、粉丝、关注数、发帖数；
- 显示关注贴吧、最近发言；
- 支持复制和打开链接。

### 3.5 黑名单

- 三级：安全（绿）/ 警告（黄）/ 禁止（红）；
- 命中优先级：禁止 > 警告 > 安全；
- 支持 Excel 导入/导出；
- 关注列表隐藏的用户：命中禁止仍为红；未命中禁止时标黄并提示风险。

### 3.6 游客模式

- Cookie 留空时自动使用客户端 protobuf 接口；
- 可抓公开帖子的楼层、每层前 10 条楼中楼、参与者、等级；
- 可查最近发言和基本信息；
- 完整楼中楼、关注列表、完整资料仍需 Cookie。

### 3.7 Android

- 同一套 Python 核心；
- WebView 界面 + 本地 HTTP 服务；
- 支持抓取、参与者、表格、查成分、黑名单、导出。

## 4. 非功能需求

- Windows 版为免安装目录，双击 exe 即可；
- 不要求目标机器安装 Python；
- 请求间隔可配置，默认 ≥0.3 秒，避免触发验证；
- Cookie 本地保存：Windows 使用 DPAPI，Android 存 App 私有目录；
- 日志不得输出 Cookie/BDUSS；
- 抓取失败要给出可理解的错误（验证、删帖、网络）；
- 支持离线自测（fixtures），不依赖网络。

## 5. 明确不做

- 不提供贴吧发帖/回复/签到等写操作；
- 不自动登录、不绕过验证码；
- 不承诺完整枚举隐藏关注列表；
- 不提供官方 API 或数据合作；
- 不做多用户 SaaS、不做公网服务。

## 6. 验收标准

- `python tests/selftest.py` 全部通过；
- 无 Cookie 能抓一个公开帖子并导出 Excel；
- 有 Cookie 能抓楼中楼、查用户资料；
- 桌面 exe `--selftest` 返回 0；
- Android APK 能启动、抓取、导出（真机验证）。
