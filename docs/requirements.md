# 需求与边界

## 1. 背景

贴吧帖子页的楼层和楼中楼没有方便的批量导出工具。本项目面向需要统计“谁回复了多少、
发了什么”的个人用户，提供 Windows 桌面程序、命令行和 Android 版。

## 2. 目标用户

- 想导出某个帖子参与情况的普通用户；
- 需要按用户筛查“成分”（关注吧、最近发言）的用户；
- 想在手机上临时抓一个公开帖子的人。

## 3. 功能需求

### 3.1 抓取

- 支持一个或多个帖子链接/帖子 ID；
- 自动识别总页数，逐页抓取主题楼层；
- 抓取楼中楼（登录模式：`totalComment` + `/p/comment`；免登录模式：客户端 protobuf，每层前 10 条）；
- 支持“最多页数”“是否抓楼中楼”“是否导出”等选项；
- 支持中途停止。

### 3.2 统计与导出

- 按用户汇总：楼层数、楼中楼数、合计、等级、头衔、首次出现楼层；
- 导出 Excel：总览、用户汇总、每帖工作表；
- 包含超链接、冻结首行、筛选、合计行。

### 3.3 参与者

- 列表展示所有参与者；
- 点选后显示：关注贴吧（含等级）、最近发言（日期/类型/贴吧/标题/内容）；
- 支持条数（5~1000）与日期范围；
- 支持一键批量刷新红绿灯（按用户设置条数与日期）；
- 红绿灯默认关闭；在「设置 → 通用」显式开启后，才显示红绿灯列和批量按钮。

### 3.4 查用户

- 按用户名 / 用户ID / 昵称查询；
- 显示昵称、用户名、ID、粉丝、关注数、发帖数；
- 显示关注贴吧、最近发言；
- 支持复制和打开链接；
- 该页只做资料查看，不参与红绿灯判定。

### 3.5 本地标记

- 默认关闭，必须在「设置 → 通用」显式开启；
- 首次开启弹一次提示：“仅用于本地记录，请勿用于挂人、骚扰或公开曝光”；
- 三级：绿色 / 黄色 / 红色；
- 命中优先级：红 > 黄 > 绿；
- 只有开启后才参与参与者红绿灯和导出标记；
- 支持 Excel 导入/导出；
- 关注列表隐藏的用户：命中红色仍为红；未命中红色时标黄并提示风险（仅登录模式）。

### 3.6 抓取模式（FR-008）

抓取前必须**显式选择**模式，禁止根据 Cookie 是否为空自动切换。

- **免登录模式（默认）**
  - 不读取、不使用 Cookie；
  - 只抓公开内容：楼层、每层前 10 条楼中楼、参与者、等级；
  - 可查最近发言和基本资料，但关注列表可能不完整；
  - 红绿灯只按**本帖发言**判定，不查关注列表（免登录查不到完整关注，
    按关注判定会误伤）。
- **登录模式**
  - 必须提供包含 `BDUSS` 的 Cookie；
  - 完整楼中楼、关注列表、完整资料、一键红绿灯（发言 + 关注）；
  - 未提供 `BDUSS` 时阻止开始，提示“切换免登录模式”或“填写 Cookie”，
    **不得静默降级为免登录**。

模式规则：

- 模式选择持久化，默认免登录；
- 已保存 Cookie 时，启动后提示可切换登录模式；
- 免登录模式下 Cookie 输入框禁用，但保留已填内容；
- 切换模式不清空已抓结果，下一次抓取按新选择执行；
- 状态栏、日志、导出信息中标注本次模式。

模式选择入口：

- **首次启动**：弹一次“选择使用方式”对话框，两张卡片（免登录 / 登录），
  默认选中免登录，勾选“记住选择”；
- **之后启动**：不再弹窗，在「抓取」页顶部保留分段选择器
  `[免登录] [登录]`，旁边显示当前模式能力提示；
- 用户随时可切换；切换登录但无 Cookie 时，展开 Cookie 区并提示；
- Android 采用同样的“首次选择 + 顶部模式卡片”，不做登录墙。

红绿灯判定：

- **免登录**：只看本帖发言吧，`classify` 后按 禁止 > 警告 > 安全；
  没有命中就是白灯；不读取关注列表，不触发“隐藏关注标黄”规则。
- **登录**：发言吧 + 关注吧 + 隐藏恢复吧；保留“隐藏关注且未命中禁止 → 黄灯 + ⚠”。
- 模式下“一键红绿灯”都可用，但免登录只跑发言判定，不发资料请求。

能力矩阵：

| 功能 | 免登录 | 登录 |
|---|---|---|
| 楼层 | ✅ | ✅ |
| 楼中楼 | 每层前 10 条 | 完整 |
| 参与者 / 等级 | ✅ | ✅ |
| 导出 Excel | ✅ | ✅ |
| 查成分 | 基本（可能不完整） | 完整 |
| 关注列表 | 部分 | 公开部分完整 |
| 一键红绿灯 | ✅（仅发言） | ✅（发言 + 关注） |

### 3.7 Android

- 同一套 Python 核心；
- WebView 界面 + 本地 HTTP 服务；
- 本轮范围：模式选择、免登录红绿灯（仅发言）、查用户、导出；
- 本轮不做：批量红绿灯、本地标记 Excel 导入导出、快照。

## 4. 非功能需求

- Windows 版为免安装目录，双击 exe 即可；
- 不要求目标机器安装 Python；
- 请求间隔可配置，默认 ≥0.3 秒，避免触发验证；
- Cookie 本地保存：Windows 使用 DPAPI，Android 存 App 私有目录；
- 日志不得输出 Cookie/BDUSS；
- 抓取失败要给出可理解的错误（验证、删帖、网络）；
- 支持离线自测（fixtures），不依赖网络。

## 5. 明确不做

- 不提供贴吧发帖/回复/签到等写操作；
- 不自动登录、不绕过验证码；
- 不承诺完整枚举隐藏关注列表；
- 不提供官方 API 或数据合作；
- 不做多用户 SaaS、不做公网服务。

## 6. 验收标准

- `python tests/selftest.py` 全部通过；
- 无 Cookie 能抓一个公开帖子并导出 Excel；
- 有 Cookie 能抓楼中楼、查用户资料；
- 桌面 exe `--selftest` 返回 0；
- Android APK 能启动、抓取、导出（真机验证）。
