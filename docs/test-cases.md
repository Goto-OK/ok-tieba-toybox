# 手工验收用例

用途：每个 1.6.0 修复项在上线前逐条执行；自动测试之外的人工检查清单。

## 回归范围

每次改动后至少执行：

```text
ruff check .
mypy
pytest
tests/selftest.py
python scripts/sync_android.py --check
```

手工回归：

- 启动、抓取、导出；
- 设置页各分类；
- 查用户；
- 参与者；
- 清空最近结果 / 清空所有数据。

## 用例

| 编号 | 前置 | 操作 | 预期 |
|---|---|---|---|
| HELP-01 | 在帖子统计页 | 点“查看使用说明” | 独立窗口打开，不切换到设置页 |
| HELP-02 | 在设置任意分类 | 点“查看使用说明” | 独立窗口打开，设置页保持原分类 |
| HELP-03 | 帮助窗口已打开 | 再按 F1 / 再点说明 | 同一窗口前置，不重复开 |
| HELP-04 | 设置页 | 查看左侧分类 | 没有“使用说明”；“关于/帮助”内有入口 |
| HEADER-01 | 浅色主题 | 查看参与者、表格、楼层、楼中楼、对比、查用户两表 | 表头为深色主题表头，白字，不出现白底 |
| HEADER-02 | 深色主题 | 同上 | 表头可读，不出现白底/黑字 |
| TRAFFIC-01 | 用户 A 在关注列表，当前帖无发言 | 一键红绿灯 | A 不被标红/黄/绿；最多显示“关注”标签 |
| TRAFFIC-02 | 用户 B 当前帖有违规发言 | 一键红绿灯 | B 在发言查询完成后标记；颜色符合规则 |
| TRAFFIC-03 | 发言查询失败 | 一键红绿灯 | 保持未标记，不猜颜色，提示失败 |
| EMOJI-01 | 查用户查询框 | 输入 😀 | 自动显示 `[U+1F600]`，光标不跳 |
| EMOJI-02 | 查用户查询框 | 粘贴 😀 | 自动转码 |
| EMOJI-03 | 输入法选 😀 | 提交后 | 自动转码，不打断输入法 |
| EMOJI-04 | 查用户工具栏 | 查看按钮 | 没有“Emoji 代码”按钮 |
| CLIP-01 | 参与者页 | 窗口缩到 900×640 | 底部橙色提示和“导出此人报告”按钮完整可见 |
| CLIP-02 | 查用户页 | 窗口缩到 900×640 | 底部按钮和提示完整可见 |
| LOOKUP-01 | 已查询过一次 | 修改年/月/日 | 不发请求；显示“条件已变更” |
| LOOKUP-02 | 已查询过一次 | 点查询 | 只发一次新请求 |
| LOOKUP-03 | 默认 50 条 | 查询 | 取够 50 条即停；不按 4 倍继续翻页 |
| LOOKUP-04 | 指定日期 | 查询 | 翻到早于开始日期立即停 |
| DELETE-01 | 应用目录外放哨兵文件 | 清空最近结果 | 哨兵、设置、标记、导出均不受影响 |
| DELETE-02 | 应用目录内放无关文件 | 清空所有数据 | 只删清单内文件；无关文件保留 |
| DELETE-03 | 应用目录内 junction 指向外部 | 清空所有数据 | 外部目标不被删除；操作中止或跳过 |
| DELETE-04 | 清空所有数据 | 查看导出文件 | Excel/Markdown 保留 |
| SKIN-01 | 1.6.0 主程序 | 查看设置/安装目录 | 无皮肤入口、无角色、无动画、无 skin 素材 |
| SKIN-02 | 旧配置含 skin | 启动 1.6.0 | 回退默认主题，不崩溃 |
