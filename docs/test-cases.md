### 真实用户日期回归（2026-10-21）

对象：`唐宋元明清总用`，匿名，50 条，日期范围 `2025-01-01` 到 `2026-10-21`。

| 场景 | 类型分布 | 日期范围 | 结果 |
|---|---|---|---|
| 近期 | 回复 46 / 主题 4 | 2026-10-02 ~ 2026-10-05 | 通过 |
| 指定日期 + 优先最近 | 回复 46 / 主题 4 | 2026-10-02 ~ 2026-10-05 | 通过 |
| 指定日期 + 优先最早 | 回复 50 / 主题 0 | 2025-01-01 ~ 2025-01-02 | 不强制类型后通过 |
| 指定日期改为近期 | 回复 46 / 主题 4 | 2026-10-02 ~ 2026-10-05 | 通过 |

修复前“优先最早”为 50 条主题帖、0 条回复。原因有两层：

1. 旧回复流每页 20 条、最多 80 页，只能翻到 2025-10，之前的回复根本没取到；
2. 取到后纯时间排序又让更早的主题帖把回复挤出 50 条。

现在回复流使用大页并翻到开始日期，不再强制类型配额，按时间返回实际数据。
