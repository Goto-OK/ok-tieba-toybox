## 0. 工作规则（硬约束）

1. **默认只改规范，不改代码**；只有明确说“开始实现 / 改代码 / 动手”才改代码。
2. **只改需求指定的代码片段**，不擅自重构无关模块。
3. 需求模糊时**主动提问**，禁止脑补。
4. 接口能力、上限、字段、认证必须有证据（源码/实测），未验证标“待验证”。
5. 每轮更新 [status.md](status.md)，区分规范 / 源码 / 测试 / 成品。
6. 只有明确说“出 exe / 出 APK”才构建。

## 1. 产品定位

- 目标用户：自己 / 小圈子；
- 开源策略：先私有，稳定后再考虑公开；
- 差异化：免登录 + 本地隐私 + Excel + Android；
- 不做：图表大屏、Web 版、发帖/回复/签到、自动登录、绕过验证码、公网 SaaS。

## 2. 全局功能

### 2.1 抓取

- 支持多个帖子链接/ID；
- 自动识别页数，逐页抓；
- 支持最多页数、是否抓楼中楼、是否导出；
- 支持中途停止。

### 2.2 统计与导出

- 按用户汇总：楼层、楼中楼、合计、等级、头衔、首次楼层；
- Excel：回复统计 / 楼层明细 / 楼中楼明细 / 帖子信息；
- 帖子信息含抓取模式、时间、完整性；
- 超链接、冻结、筛选、合计行；
- 导出不写红绿灯/标记。

### 2.3 参与者

- 列表展示参与者；
- 点开看关注贴吧、最近发言；
- 条数 5~1000、日期范围；
- 红绿灯默认关闭；
- 关注隐藏时可“探测候选关注”。

### 2.4 查用户

- 按用户名 / ID / 昵称查询；
- 显示昵称、用户名、ID、粉丝、关注数、发帖数；
- 显示关注贴吧、最近发言；
- 资料页不参与红绿灯；
- 关注隐藏时可按候选吧探测 `is_follow`。

### 2.5 本地标记

- 默认关闭，设置里开启；
- 首次开启弹免责提示；
- 绿 / 黄 / 红，优先级 红 > 黄 > 绿；
- 关闭时不显示标记列、不标色、导出不带；
- 支持 Excel 导入导出；
- 关注隐藏：命中红仍红；未命中红标黄 + ⚠（仅登录模式）。

## 3. 抓取模式（FR-008）

- 必须显式选择，禁止按 Cookie 是否存在自动切换；
- 默认免登录；
- 首次启动弹一次选择，之后顶部 `[免登录] [登录]` 切换；
- 模式持久化；
- 免登录不读取/发送 Cookie；
- 登录必须含 BDUSS，缺失阻止开始、不降级；
- 免登录 Cookie 输入框禁用但保留内容；
- 切换模式不清空已抓结果；
- 状态、日志、导出标注模式。

| 能力 | 免登录 | 登录 |
|---|---|---|
| 楼层 | ✅ | ✅ |
| 楼中楼 | 完整（FR-014 目标） | 完整 |
| 参与者/等级 | ✅ | ✅ |
| 查用户 | 基本，关注可能不全 | 完整 |
| 红绿灯 | 只判发言 | 发言 + 关注 |

## 4. 红绿灯

- 免登录：只看本帖发言，不查关注，不触发隐藏标黄；
- 登录：发言 + 关注 + 隐藏恢复；隐藏且未命中禁止 → 黄 + ⚠；
- 一键红绿灯两种模式都可用，免登录不发资料请求；
- 关闭时完全不参与；
- 候选确认的 `is_follow` 可参与，但隐藏风险规则保留。

## 5. 参与者筛选（FR-009，未实现）

- 关键词：昵称 / 用户名 / ID，兼容 `[U+XXXX]`；
- 等级：固定区间 + 自定义最低/最高；
- 标记：全部 / 红 / 黄 / 绿 / 白（仅红绿灯开启时）；
- 条件取交集，实时刷新，清除按钮；
- 显示“当前 X / 共 Y 人”；
- 只影响显示，选中行仍对应原用户；
- 重新抓取/刷新清空；
- 导出时若筛选生效，弹窗问“全部 / 当前筛选”。

## 6. 多帖参与者对比（FR-010，未实现）

- 入口：表格查看 → 参与者对比；
- 至少选 2 帖；
- 固定四种：交集 / 并集 / 仅在 A / A−B；
- A、B = 勾选顺序前两个；
- 匹配：UID → 用户名 → 昵称；
- 结果列：昵称、用户名、ID、各帖计数、合计、类型；
- 只读本地数据，不联网；
- 可排序、复制、导出当前结果。

## 7. 单用户报告（FR-011，未实现）

- 入口：查用户页 / 参与者右键；
- 输出 Excel + Markdown，同目录同文件名；
- Excel：基本信息、关注贴吧、最近发言、本帖参与、本地标记（仅启用时）；
- 免登录关注表标注“可能不完整”；
- 不包含 Cookie；
- 文件名 emoji 用 `[U+XXXX]` 或 ID。

## 8. 配置备份 / 恢复（FR-012，未实现）

- 入口：设置 → 通用；
- 范围：设置 + 本地标记，不含 Cookie；
- 格式：JSON + ZIP（ZIP 内 `config.json` + `README.txt`）；
- JSON 含 `schema_version`、`kind`、`exported_at`；
- 恢复：预览 → 覆盖确认 → 临时备份 → 写入；
- 损坏/版本不支持不覆盖。

## 9. 吧务删除内容（FR-013，未实现）

- 前提：登录 + 吧务权限 + STOKEN；
- 独立「吧务」标签；
- 按用户查被删回复/主题；
- 接口：`get_recovers` 列表，`get_recover_info` 详情；
- 列表：类型、标题、内容、作者、删除时间、操作人、tid/pid、是否屏蔽；
- 严格只读，不恢复/删除/屏蔽；
- 无权限、缺 STOKEN、无结果分别提示；
- 只覆盖后台保留期内、可恢复内容；
- 本期不做全吧删除日志。

## 10. 全量楼中楼（FR-014，未实现）

- 当前源码仍是 page 接口每层 10 条预览；
- 目标：每层用 `/c/f/pb/floor?cmd=302002` 翻页；
- 默认全部，可选每层 10 / 50 / 100；
- 并发可配置 1~3，默认 1；
- 免登录只走 floor；失败保留预览 + 警告；
- 登录：floor 优先，失败回退 `totalComment` + `/p/comment`；
- 每层最多 50 页，单帖最多 2000 次请求；
- 按 pid 去重，支持停止、逐层进度；
- 匿名已实测；登录态 floor 待实测。

## 11. 隐藏关注候选探测（FR-015，已实现桌面）

- 前提：`followed_private` 或 `priv_like=3`；
- 入口：查用户页 / 参与者详情；
- 候选：本帖发言吧、最近发言吧、本地标记吧；
- 去重、排除公开关注，最多 30 个；
- 逐个 `get_user_forum_info` 取 `is_follow`；
- 关注表加「来源」：公开 / 精选 / 等级恢复 / 候选确认；
- 标注“推断，仍可能不完整”；
- 手动触发、可停止、结果不写配置/备份；
- 不能全量枚举，不做全站遍历；
- 匿名实测可用；登录态未单独验证。

## 12. 凭据

- Cookie 是整段容器；BDUSS 是登录核心；STOKEN 是敏感操作令牌；
- 普通抓取推荐只填 BDUSS；
- 整段 Cookie 也可，但包含 STOKEN；
- 吧务功能需要 STOKEN：整段 Cookie 自动解析，缺失时手动补；
- 全部 DPAPI 保存，不写日志、不导出、不进备份；
- 免登录不发送 Cookie。

## 13. 技术架构

- 核心包 `tieba_reply_stats/`；
- 入口：tkinter GUI、CLI、Android HTTP；
- 页面：网页 HTML（登录）+ 客户端 protobuf（匿名）；
- 楼中楼：`page` 预览 + `floor` 翻页；
- 用户：profile / userpost / panel / user_json；
- 隐藏关注：likeForum / panel / thread level / `get_user_forum_info`；
- 协议细节见 [protocol.md](protocol.md)。

## 14. 工程规范

- Python 3.10+，UTF-8，LF；
- ruff、mypy、pytest、selftest；
- 提交前：

```bash
python -m ruff check .
python -m mypy
python -m pytest
python tests/selftest.py
```

- 版本唯一来源 `tieba_reply_stats/version.py`；
- 接口结论必须附证据；
- Android 核心副本由 `scripts/sync_android.py` 同步，禁止手改。
