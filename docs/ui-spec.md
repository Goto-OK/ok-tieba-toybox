# 界面规范（UI）

本文件只写“界面怎么呈现、怎么交互”，不重复功能规则。  
功能行为见 [requirements.md](requirements.md)，凭据见 [credentials.md](credentials.md)。

## UI-001 一键红绿灯按钮

- 按钮文案固定为 **“一键红绿灯”**，不追加“（仅发言）”等括号说明；
- 运行中固定为 **“停止查询”**；
- 停止中固定为 **“正在停止…”**；
- 按钮宽度必须容纳 5 个汉字；
- 默认窗口和最小窗口下都不能出现半个括号、省略号或截断；
- 模式说明放在按钮外：
  - 红绿灯范围跟随参与者当前“帖子范围”：
  - 全部帖子：所有已抓帖子；
  - 单帖：只算该帖；
- 免登录：按钮旁或参与者提示区显示“仅发言判定”；
  - 登录：显示“发言 + 关注”；
- 禁止把模式说明塞进按钮文案。

## UI-002 运行日志

- 日志固定在「抓取」页底部，默认展开；
- 最小高度 150px，约 8 行；
- 上方表单区域可滚动；窗口变小时优先压缩表单，不把日志压到不可见；
- 最小窗口下日志至少保留 6 行；
- 日志可折叠，但默认展开；
- 折叠后标题显示“运行日志（已折叠）”，不能完全消失；
- 运行中自动滚动到底部；
- 用户手动上滚后不强制抢回焦点，除非用户自己切回底部；
- 日志滚动条始终可用。

## UI-003 默认窗口与布局

- 默认窗口建议 980×820；
- 最小窗口 840×680；
- 屏幕工作区不足时按工作区高度自适应，但不能低于最小高度；
- 不允许出现“控件被窗口边缘裁掉且无法滚动”的情况；
- 主页面使用可调整的分区，日志和表单之间的空间可拖动。

验收工作区：

```text
1280×720
1366×768
1920×1080
```

默认打开即可看到至少 6 行日志；不最大化、不拖动窗口也能看到最近一条错误。

## UI-004 主导航

顶部标签固定为：

```text
帖子统计
查用户
设置
```

「帖子统计」内部子标签固定为：

```text
抓取
表格查看
参与者
```

- 首次启动不弹“选择使用方式”；
- 「抓取」页顶部不再放 `[免登录] [登录]` 选择器；
- 关注增强只在「设置 → 高级」出现。

## UI-005 文案

统一使用：

| 场景 | 文案 |
|---|---|
| 查人 | 查用户 |
| 本地记录 | 本地标记 |
| 关注增强 | 设置 → 高级 → 关注增强 |
| 红绿灯 | 一键红绿灯 |

禁止使用：

- 查成分；
- 黑名单（指本地标记时）；
- 一键红绿灯（仅发言）作为按钮文案。

## UI-006 参与者筛选

- 筛选条位于参与者列表上方；
- 顶部提供“帖子范围”下拉：
  - `全部帖子（N 帖）`（默认）；
  - 每个已抓帖子；
- 默认“全部帖子”，显示跨帖合计；
- 下拉项显示帖子标题/吧名，不只显示 tid；
- 切换只影响参与者页，不改变表格查看当前帖子；
- 切换范围时保留筛选，清空选中行；
- 无匹配用户时显示空状态提示；
- 包含关键词、等级、标记、清除筛选；
- 等级选“自定义”时才显示最低/最高输入框；
- 标记筛选仅在本地标记开启时可用（默认开启），关闭时禁用并重置为“全部”；
- 右上角显示 `当前 X / 共 Y 人`；
- 筛选只影响显示，选中行仍对应原用户；
- 重新抓取时清空筛选。

## UI-007 表格

- 顶部提供“帖子切换”：
  - 每个已抓帖子；
  - `全部帖子（汇总）`（非默认）；
- 默认第一个帖子，切换后表头和明细同步切换；
- 全部汇总时：
  - 回复统计按用户跨帖合计，增加“参与帖子数”；
  - 增加“分帖统计”子表（仅全部汇总时显示）：一行 = 用户 × 帖子；
  - 楼层/楼中楼明细增加“帖子”列，按帖子分组；
  - 分帖统计同样跟随导出用户范围；
- 表头可排序；
- 双击链接打开浏览器；
- 内容列自动换行或省略，但不能把关键列挤没；
- 关注表必须有「来源」列：公开 / 精选 / 等级恢复 / 候选确认；
- 参与者对比不套用参与者筛选，范围只由勾选帖子决定；
- 对比导出固定：参与者对比 + 导出说明（最后）；
- 候选确认行标注“推断”，不能显示成完整关注列表。

## UI-008 查用户

- 查询方式：用户名 / 用户 ID / 昵称；
- 昵称输入框接受原始 emoji 和 `[U+XXXX]` 代码；
- 输入框旁提示“昵称支持 [U+XXXX] emoji 代码”；
- 提供「Emoji 代码」按钮：输入十六进制后插入 `[U+XXXX]`；
- 日期范围用年 / 月 / 日下拉，默认近 3 个月；
- 「设置 → 高级 → 查看用户资料时加载公开关注」：自动（默认）/ 手动；
- 查用户页和参与者详情页共用该设置；
- 仅关注增强开启时生效；
- 自动：
  - 先显示基本资料，再加载公开关注；
  - 同一会话同一用户默认只加载一次；
  - 提供「刷新关注」；
- 手动：
  - 查用户页和参与者详情页都显示「加载公开关注」按钮；
  - 点击才请求；
- 未开启关注增强时：
  - 允许匿名尝试读取公开关注；
  - 成功时关注表标注“匿名尝试，可能不完整”；
  - 失败时显示“未开启关注增强，关注列表不完整”；
  - 关注区固定提示：“公开关注为匿名尝试，可能失败/不完整；要稳定读取请开启关注增强；隐藏关注仍不可见”；
- 关注隐藏时才显示「探测候选关注」；
- 「导出报告」生成 Excel + Markdown；
- 基本信息里记录软件版本、帖子范围、关注数据状态；
- 不单独增加“报告说明”工作表；
- 参与者详情发起的报告跟随当前帖子范围；
- 查用户页发起的报告默认统计所有已抓帖子；
- 报告只使用当前已加载的关注数据，不额外请求；
- 手动模式未加载时，报告标注“未加载公开关注，关注列表不完整”；
- 查用户页不参与本地红绿灯。

## UI-009 配置备份

- 入口在「设置 → 通用」；
- 两个按钮：「备份配置」「恢复配置」；
- 备份说明必须写“只含非敏感设置和本地标记，不含 Cookie、不含最近结果”；
- 备份范围包含所有非敏感设置，不包含 Cookie 值和最近结果；
- 恢复前显示预览并二次确认；
- 恢复后立即生效，不要求重启；
- 当前已抓结果不受影响；
- 关注增强因缺 Cookie 被强制关闭时，要明确提示；
- 加密转换失败时保留原文件并提示。

## UI-010 关注增强

- 入口只在「设置 → 高级」；
- 默认关闭；
- 勾选后展开凭据输入区，提供两个选项：
  - `[仅 BDUSS]`（默认，推荐）；
  - `[整段 Cookie]`；
- 仅 BDUSS：输入框只收 `BDUSS=...` 或纯 BDUSS 值；
- 整段 Cookie：接受 `k=v; k=v` 整段，内部只提取 BDUSS；
- 两种方式能力相同，整段 Cookie 不增加功能；
- 「记住 BDUSS」默认勾选；
- 取消后只在本次会话使用；
- 整段 Cookie 中的 STOKEN 不读取、不使用、不落盘；
- 保存时只保存 BDUSS；
- 说明必须写“只读公开关注，隐藏关注仍不完整”；
- 开启/关闭立即生效，不需要重启；
- 不显示 Cookie/BDUSS 明文；
- 关闭后红绿灯回到仅发言判定；
- 启动时恢复上次明确开启状态；无 BDUSS 则强制关闭并提示；
- 启动不强制联网校验 BDUSS；
- 第一次开启时立即验证一次；
- 验证中显示加载状态；
- 无法验证（网络/验证码）时保持关闭，不误判为 BDUSS 错误。

## UI-011 反馈与状态

- 开始、停止、完成、失败都要有明确状态；
- 长任务显示进度或已完成人数；
- 错误信息必须能看懂，不能只显示异常类型；
- 停止后保留已完成结果；
- 日志颜色只用于区分信息等级，不替代文字。

## UI-012 本地标记开关

- 「设置 → 通用 → 启用本地标记与红绿灯」保留，不删除；
- 默认勾选；新安装或配置缺失时按开启处理；
- 用户显式关闭过则保持关闭；
- 首次启动且开启时显示一次免责提示，不阻塞使用；
- 关闭后：
  - 参与者列表隐藏标记列；
  - 表格不标色；
  - 「一键红绿灯」禁用；
  - 名单仍保留，导入/导出仍可用。

## UI-013 多帖切换与导出范围

- 「表格查看」和「参与者」都能选择帖子；
- 表格查看：默认第一个帖子，另有“全部帖子（汇总）”；
- 参与者：默认“全部帖子”，也可切到单帖；
- 「导出 Excel」「打开 Excel」共用“选择范围”对话框：
  - 帖子范围：当前表格范围（默认）/ 全部帖子 / 勾选帖子（可全选/反选）；
  - 用户范围：全部用户（默认）/ 当前筛选用户；
  - “当前筛选用户”仅在筛选生效时显示；
  - 筛选用户为空时提示，不生成文件；
  - Excel 工作表顺序固定：回复统计 → 分帖统计（仅全部汇总）→ 楼层明细 → 楼中楼明细 → 帖子信息 → 导出说明（最后）；
  - Excel 包含「导出说明」工作表，固定最后一个：生成时间、版本、帖子范围、用户范围、筛选条件、关注增强状态、空帖列表；
  - 临时工作簿放系统临时目录 `TiebaReplyStats` 子目录；
  - 下次启动清理旧 `open_*.xlsx`，被占用的跳过；
  - 筛选后有帖子为空：跳过空表，总览保留并标 0；
  - 所有帖子都为空：提示，不生成文件；
- 导出保存到指定路径；
- 打开用同一选择生成临时工作簿并打开；
- 未勾选任何帖子时提示，不生成空文件；
- 多帖结果不能互相覆盖；
- 再次抓取新帖时，已抓帖子保留，不重复抓；
- 「设置 → 高级 → 再次抓取时自动刷新已抓帖子」：
  - 默认关闭；
  - 关闭：跳过已抓帖子；
  - 开启：刷新旧帖 + 追加新帖；
  - 开启时提示“会明显变慢”；
- 刷新成功替换当前结果，不合并旧内容；
- 「设置 → 高级 → 再次抓取时处理已移除帖子」：
  - 保留旧结果（默认）；
  - 移除旧结果；
  - 每次询问；
- 选项只在开始抓取时生效，不即时删除；
- 选“询问”时列出被移除帖子，让用户选择；
- 「清空结果」始终删除全部。

## UI-014 Emoji 显示与输入

显示策略：

- Tk 界面中的用户昵称、用户名、头衔、标题、正文里的 emoji，
  统一显示为 `[U+XXXX]` 代码；
- 表格查看、参与者、查用户、日志、对话框都使用同一规则；
- 静态界面图标（⚪ / ⚠ / ✅ 等）不属于用户数据，不转码；
- Excel、Markdown 报告保留原始 emoji；
- 不允许同一个昵称在“表格查看”和“参与者”显示成两种形式。

输入：

- 昵称输入框接受原始 emoji；
- 也接受 `[U+XXXX]` 代码；
- 两种写法等价；
- 提供「Emoji 代码」按钮：输入十六进制后插入 `[U+XXXX]`；
- 非法代码给出错误，不静默替换。

提示：

- 查用户输入框旁显示：
  “界面用 [U+XXXX] 显示 emoji，导出 Excel 保留原样”；
- 表格查看顶部显示同一句提示；
- 首次打开表格查看时提示一次，不弹窗、不阻塞。

## UI-015 最近结果持久化

- 「设置 → 高级 → 保存最近结果」默认开启；
- 「设置 → 高级 → 启动时恢复上次结果」：自动 / 询问，默认自动；
- 「设置 → 高级 → 加密保存最近结果」默认关闭；
- 加密开关旁提示“换 Windows 用户/换电脑无法恢复”；
- 关闭保存后退出删除本地结果；
- 自动恢复时状态栏显示“已恢复上次结果（时间）”；
- 询问时弹窗提供：恢复 / 跳过（文件保留）/ 删除；
- 恢复不自动抓取；
- 「清空结果」同时清本地文件；
- 删除失败要提示。

## UI-017 设置页布局

设置页改为左侧分类 + 右侧内容：

```text
常规
关注增强
抓取行为
结果与存储
本地标记
关于 / 帮助
```

- 左侧是分类列表，右侧是当前分类内容；
- 右侧内容可滚动，不能把控件挤出窗口；
- 默认打开「常规」；
- 「设置 → 常规 → 打开设置时停在」：
  - 常规（默认）；
  - 上次分类；
- 选“上次分类”时，记住上次选中的左侧分类；分类不存在则回退常规；
- 不嵌套子标签；
- 分类切换不丢未保存的输入；
- 常规/关注增强/抓取行为/结果与存储：改动立即保存，不设“应用”按钮；
- 本地标记：保留显式「保存本地标记」；
- 关于/帮助：版本、使用说明、免责声明、项目链接；
- 最小窗口下左侧分类不折行，右侧可滚动。

### 常规

- 红绿灯总开关（默认开启）；
- 行标色开关：
  - 参与者列表；
  - 关注的贴吧；
  - 最近发言；
- 不在这里放 Cookie、抓取间隔、并发、持久化等高级项。

### 关注增强

- 关注增强开关；
- 仅 BDUSS / 整段 Cookie；
- 查看用户资料时加载公开关注：自动 / 手动。

### 抓取行为

- 自动刷新旧帖；
- 移除旧帖处理；
- 请求间隔、楼中楼深度、并发继续留在「抓取」页，不搬进设置；
- 设置只放跨次策略。

### 结果与存储

- 保存最近结果；
- 启动恢复方式；
- 加密保存；
- 清空本地结果。

### 本地标记

- 安全 / 警告 / 禁止名单；
- 导入 / 导出；
- 保存按钮。

### 关于 / 帮助

- 版本；
- 使用说明；
- 免责声明；
- 项目链接。

## UI-018 关于 / 数据清理

- 入口在「关于 / 帮助」；
- 显示数据目录和临时目录，提供「打开文件夹」；
- 提供两个操作：
  - 恢复默认设置；
  - 清空所有本地数据；
- 提供「查看快速说明」按钮；
- 提供「复制诊断信息」按钮；
- 提供「第三方组件与许可」入口（只读）；
- 两个操作都必须二次确认；
- 确认框分两栏列出“会删除 / 不会删除”；
- 「恢复默认设置」保留结果、标记、BDUSS、导出文件；
- 「清空所有本地数据」删除软件管理的数据，不删除导出文件；
- 标题写“清空软件数据（不会删除导出文件）”；
- 弹窗必须分两栏：
  - 会删除：结果、BDUSS、本地标记、设置、临时文件、缓存；
  - 不会删除：导出的 Excel、Markdown、其他位置的文件；
- 二次确认 + 输入“清空”；
- 默认按钮“取消”；
- 完成后提示“导出文件未受影响”；
- 清空后立即刷新为默认状态，不要求重启；
- 清空失败逐项提示。

## UI-019 首次启动引导

- 首次启动显示一次，非阻塞；
- 不提供“免登录/登录”选择；
- 内容：
  - 默认匿名，不需要 Cookie；
  - 红绿灯/本地标记默认开启，仅本地；
  - 关注增强默认关闭，入口在设置；
  - 免责提示；
  - 「查看使用说明」；
- 关闭后不再自动弹；
- 「关于 / 帮助」提供「查看快速说明」，可随时重看；
- 重看不改首次标记；
- 与本地标记免责提示合并，不连续弹窗；
- 清空所有数据后，下次启动重新显示；
- 恢复默认设置不重置该标记。

## UI-020 验收

- 默认打开时红绿灯开关为开启；
- 关闭开关后标记列、颜色、按钮状态正确；
- 840px 宽窗口下「一键红绿灯」完整显示；
- 默认窗口和 1366×768 下日志可见；
- 筛选、对比、报告、备份、关注增强页面无控件被裁切；
- 所有按钮文案不出现半个括号；
- 默认匿名红绿灯按钮旁明确写“仅发言判定”；
