# 界面规范（UI）

本文件只写“界面怎么呈现、怎么交互”，不重复功能规则。  
功能行为见 [requirements.md](requirements.md)，凭据见 [credentials.md](credentials.md)。

## UI-001 一键红绿灯按钮

- 按钮文案固定为 **“一键红绿灯”**，不追加“（仅发言）”等括号说明；
- 运行中固定为 **“停止查询”**；
- 停止中固定为 **“正在停止…”**；
- 按钮宽度必须容纳 5 个汉字；
- 默认窗口和最小窗口下都不能出现半个括号、省略号或截断；
- 模式说明放在按钮外：
  - 免登录：按钮旁或参与者提示区显示“仅发言判定”；
  - 登录：显示“发言 + 关注”；
- 禁止把模式说明塞进按钮文案。

## UI-002 运行日志

- 日志固定在「抓取」页底部，默认展开；
- 最小高度 150px，约 8 行；
- 上方表单区域可滚动；窗口变小时优先压缩表单，不把日志压到不可见；
- 最小窗口下日志至少保留 6 行；
- 日志可折叠，但默认展开；
- 折叠后标题显示“运行日志（已折叠）”，不能完全消失；
- 运行中自动滚动到底部；
- 用户手动上滚后不强制抢回焦点，除非用户自己切回底部；
- 日志滚动条始终可用。

## UI-003 默认窗口与布局

- 默认窗口建议 980×820；
- 最小窗口 840×680；
- 屏幕工作区不足时按工作区高度自适应，但不能低于最小高度；
- 不允许出现“控件被窗口边缘裁掉且无法滚动”的情况；
- 主页面使用可调整的分区，日志和表单之间的空间可拖动。

验收工作区：

```text
1280×720
1366×768
1920×1080
```

默认打开即可看到至少 6 行日志；不最大化、不拖动窗口也能看到最近一条错误。

## UI-004 主导航

顶部标签固定为：

```text
帖子统计
查用户
设置
```

「帖子统计」内部子标签固定为：

```text
抓取
表格查看
参与者
```

- 首次启动不弹“选择使用方式”；
- 「抓取」页顶部不再放 `[免登录] [登录]` 选择器；
- 关注增强只在「设置 → 高级」出现。

## UI-005 文案

统一使用：

| 场景 | 文案 |
|---|---|
| 查人 | 查用户 |
| 本地记录 | 本地标记 |
| 关注增强 | 设置 → 高级 → 关注增强 |
| 红绿灯 | 一键红绿灯 |

禁止使用：

- 查成分；
- 黑名单（指本地标记时）；
- 一键红绿灯（仅发言）作为按钮文案。

## UI-006 参与者筛选

- 筛选条位于参与者列表上方；
- 顶部提供“帖子范围”：全部帖子 / 单个帖子；
- 默认“全部帖子”；
- 包含关键词、等级、标记、清除筛选；
- 等级选“自定义”时才显示最低/最高输入框；
- 标记筛选仅在本地标记开启时可用（默认开启），关闭时禁用并重置为“全部”；
- 右上角显示 `当前 X / 共 Y 人`；
- 筛选只影响显示，选中行仍对应原用户；
- 重新抓取时清空筛选。

## UI-007 表格

- 顶部提供“帖子切换”，列出所有已抓帖子；
- 默认第一个帖子，切换后表头和明细同步切换；
- 表头可排序；
- 双击链接打开浏览器；
- 内容列自动换行或省略，但不能把关键列挤没；
- 关注表必须有「来源」列：公开 / 精选 / 等级恢复 / 候选确认；
- 候选确认行标注“推断”，不能显示成完整关注列表。

## UI-008 查用户

- 查询方式：用户名 / 用户 ID / 昵称；
- 昵称输入框接受原始 emoji 和 `[U+XXXX]` 代码；
- 输入框旁提示“昵称支持 [U+XXXX] emoji 代码”；
- 提供「Emoji 代码」按钮：输入十六进制后插入 `[U+XXXX]`；
- 日期范围用年 / 月 / 日下拉，默认近 3 个月；
- 未开启关注增强时显示“关注列表可能不完整”；
- 关注隐藏时才显示「探测候选关注」；
- 「导出报告」生成 Excel + Markdown；
- 查用户页不参与本地红绿灯。

## UI-009 配置备份

- 入口在「设置 → 通用」；
- 两个按钮：「备份配置」「恢复配置」；
- 备份说明必须写“只含设置和本地标记，不含 Cookie”；
- 备份范围包含关注增强开关，不包含 Cookie 值；
- 恢复前显示预览并二次确认；
- 恢复失败不能覆盖现有配置。

## UI-010 关注增强

- 入口只在「设置 → 高级」；
- 默认关闭；
- 勾选后展开 Cookie 输入框，必须包含 BDUSS；
- 说明必须写“只读公开关注，隐藏关注仍不完整”；
- 开启/关闭立即生效，不需要重启；
- 不显示 Cookie/BDUSS 明文；
- 关闭后红绿灯回到仅发言判定。

## UI-011 反馈与状态

- 开始、停止、完成、失败都要有明确状态；
- 长任务显示进度或已完成人数；
- 错误信息必须能看懂，不能只显示异常类型；
- 停止后保留已完成结果；
- 日志颜色只用于区分信息等级，不替代文字。

## UI-012 本地标记开关

- 「设置 → 通用 → 启用本地标记与红绿灯」保留，不删除；
- 默认勾选；新安装或配置缺失时按开启处理；
- 用户显式关闭过则保持关闭；
- 首次启动且开启时显示一次免责提示，不阻塞使用；
- 关闭后：
  - 参与者列表隐藏标记列；
  - 表格不标色；
  - 「一键红绿灯」禁用；
  - 名单仍保留，导入/导出仍可用。

## UI-013 多帖切换

- 「表格查看」和「参与者」都能选择帖子；
- 表格查看：默认第一个帖子，切换后同步；
- 参与者：默认“全部帖子”，也可切到单帖；
- 多帖结果不能互相覆盖；
- 再次抓取新帖时，已抓帖子保留，不重复抓。

## UI-014 Emoji 查询

- 昵称输入框不过滤 emoji；
- 支持直接输入 emoji，也支持 `[U+XXXX]`；
- 两种写法等价；
- 非法代码给出错误；
- 显示时可用 `[U+XXXX]`，但输入不能被转换成别的字符。

## UI-015 验收

- 默认打开时红绿灯开关为开启；
- 关闭开关后标记列、颜色、按钮状态正确；
- 840px 宽窗口下「一键红绿灯」完整显示；
- 默认窗口和 1366×768 下日志可见；
- 筛选、对比、报告、备份、关注增强页面无控件被裁切；
- 所有按钮文案不出现半个括号；
- 默认匿名红绿灯按钮旁明确写“仅发言判定”。
