# 界面规范（UI）

本文件只写“界面怎么呈现、怎么交互”，不重复功能规则。  
功能行为见 [requirements.md](requirements.md)，凭据见 [credentials.md](credentials.md)。

## UI-001 一键红绿灯按钮

- 按钮文案固定为 **“一键红绿灯”**，不追加“（仅发言）”等括号说明；
- 运行中固定为 **“停止查询”**；
- 停止中固定为 **“正在停止…”**；
- 按钮宽度必须容纳 5 个汉字；
- 默认窗口和最小窗口下都不能出现半个括号、省略号或截断；
- 模式说明放在按钮外：
  - 免登录：按钮旁或参与者提示区显示“仅发言判定”；
  - 登录：显示“发言 + 关注”；
- 禁止把模式说明塞进按钮文案。

## UI-002 运行日志

- 日志固定在「抓取」页底部，默认展开；
- 最小高度 150px，约 8 行；
- 上方表单区域可滚动；窗口变小时优先压缩表单，不把日志压到不可见；
- 最小窗口下日志至少保留 6 行；
- 日志可折叠，但默认展开；
- 折叠后标题显示“运行日志（已折叠）”，不能完全消失；
- 运行中自动滚动到底部；
- 用户手动上滚后不强制抢回焦点，除非用户自己切回底部；
- 日志滚动条始终可用。

## UI-003 默认窗口与布局

- 默认窗口建议 980×820；
- 最小窗口 840×680；
- 屏幕工作区不足时按工作区高度自适应，但不能低于最小高度；
- 不允许出现“控件被窗口边缘裁掉且无法滚动”的情况；
- 主页面使用可调整的分区，日志和表单之间的空间可拖动。

验收工作区：

```text
1280×720
1366×768
1920×1080
```

默认打开即可看到至少 6 行日志；不最大化、不拖动窗口也能看到最近一条错误。

## UI-004 主导航

顶部标签固定为：

```text
帖子统计
查用户
吧务
设置
```

「帖子统计」内部子标签固定为：

```text
抓取
表格查看
参与者
```

- 首次启动弹一次“选择使用方式”；
- 之后在「抓取」页顶部保留 `[免登录] [登录]` 选择器；
- 模式说明放在选择器旁，不塞进按钮。

## UI-005 文案

统一使用：

| 场景 | 文案 |
|---|---|
| 查人 | 查用户 |
| 本地记录 | 本地标记 |
| 抓取模式 | 免登录 / 登录 |
| 红绿灯 | 一键红绿灯 |
| 吧务 | 吧务（只读） |

禁止使用：

- 查成分；
- 黑名单（指本地标记时）；
- 一键红绿灯（仅发言）作为按钮文案。

## UI-006 参与者筛选

- 筛选条位于参与者列表上方；
- 包含关键词、等级、标记、清除筛选；
- 等级选“自定义”时才显示最低/最高输入框；
- 标记筛选仅在本地标记开启时可用，关闭时禁用并重置为“全部”；
- 右上角显示 `当前 X / 共 Y 人`；
- 筛选只影响显示，选中行仍对应原用户；
- 重新抓取时清空筛选。

## UI-007 表格

- 表头可排序；
- 双击链接打开浏览器；
- 内容列自动换行或省略，但不能把关键列挤没；
- 关注表必须有「来源」列：公开 / 精选 / 等级恢复 / 候选确认；
- 候选确认行标注“推断”，不能显示成完整关注列表。

## UI-008 查用户

- 查询方式：用户名 / 用户 ID / 昵称；
- 日期范围用年 / 月 / 日下拉，默认近 3 个月；
- 免登录显示“关注列表可能不完整”；
- 关注隐藏时才显示「探测候选关注」；
- 「导出报告」生成 Excel + Markdown；
- 查用户页不参与本地红绿灯。

## UI-009 配置备份

- 入口在「设置 → 通用」；
- 两个按钮：「备份配置」「恢复配置」；
- 备份说明必须写“只含设置和本地标记，不含 Cookie”；
- 恢复前显示预览并二次确认；
- 恢复失败不能覆盖现有配置。

## UI-010 吧务页

- 顶部必须显示“只读：不提供恢复/删除”；
- 有吧名、用户、页码、STOKEN 状态；
- STOKEN 只显示“已检测到/未检测到”，不显示明文；
- 列表列：类型、标题、内容、作者、操作时间、操作人、状态；
- 详情区显示标题、作者、tid/pid、正文；
- 无权限、缺 STOKEN、无结果分别提示。

## UI-011 反馈与状态

- 开始、停止、完成、失败都要有明确状态；
- 长任务显示进度或已完成人数；
- 错误信息必须能看懂，不能只显示异常类型；
- 停止后保留已完成结果；
- 日志颜色只用于区分信息等级，不替代文字。

## UI-012 验收

- 840px 宽窗口下「一键红绿灯」完整显示；
- 默认窗口和 1366×768 下日志可见；
- 筛选、对比、报告、备份、吧务页面无控件被裁切；
- 所有按钮文案不出现半个括号；
- 免登录红绿灯按钮旁明确写“仅发言判定”。
